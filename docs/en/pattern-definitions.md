## 新定義與保存

新增版本須保留父版本、差異、原始來源／hash、批准證據、正反例及 `known_at`；未核准標註不能改成擁有者確認。過去期間暴露與比較次數仍沿用原紀錄，不因改名或共用快取變成未見樣本。完整 owner 標註匯出由 Claude 的獨立 task 交付；這裡的 25 原例不是那批標註的替代品。
