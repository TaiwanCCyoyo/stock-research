狀態：討論草案，2026-10-02（台北）。已與「飆股分類」session 完成雙向資料／UX 對齊。本次交付是設計、唯讀盤點與互動概念，尚未實作正式網站、資料管線或任何新回測。新時間軸概念採分類 v1 的真實摘錄；原策略概念仍使用合成資料，兩者均不是策略成效證據。

## 1. 建議方向

重設網站的產品架構、UX、設計系統與 API 投影契約。現有網站可提供歷史相容性參考，但其畫面、分頁、任務格式及讀取方法不構成新設計限制。

做一個長期可維護的「策略研究工作台」：策略圖鑑、完整研究歷程、帳戶回測、逐筆證據、ETF 方法與績效比較、飆股時光圖共用同一套導航、時間選取與證據操作。保留一個正式前端，避免每個研究 agent 或任務各做一個網站。

**第一版以「全市場勢力地圖」作主入口，與「策略工作台」互相連結。** 使用者像觀看歷史版圖的興衰一樣，只拖時間，族群與個股就自行浮現、壯大、轉入退場；不先限定族群。現在已有完整的事後族群 catalog，時間軸不必等 ETF 歷史持股或決策快照才開始做。行情頁回答「那段時間發生什麼」；策略頁回答「這個方法實際做了什麼」；證據抽屜讓兩者能在相同股票、日期與版本下核對。

2026-10-02 owner 修正：原概念先選族群再看共同窗口，與期望不符；改成**全市場探索 → 看勢力交替 → 點勢力或個股 → 查證據／同期比較**。族群比較桌保留作第二層明細，不能重新成為進入地圖的必要步驟。

網站首先回答五個問題：

1. 這個方法實際做什麼？
2. 哪些年份賺、哪些年份虧，反覆試錯損失多少錢？
3. 這個結果還缺什麼驗證，哪些假設可能改變結論？
4. 點開任何數字或交易，能否核對當時資料、規則、成交與帳戶收支？
5. 相同期間與口徑下，和可以直接持有的 ETF 相比，研究方法有什麼價值？

漂亮的呈現服務於這些問題：克制的色彩、清楚的留白與數字層級、可同步的圖表和表格、可暫停的事件回放。手機能查詢與分享指定事件；桌面適合多方法比較。

2026-10-02 Owner 指定的新版規則取代先前線性面積提案。對有效正漲幅 `g` 及正市值 `M`，`area_weight = (g / g_ref)^2 × (M / M_ref)^alpha`，其中 `alpha = ln(1.25) / ln(100)`，等效直徑與 `sqrt(area_weight)` 成正比。市值每跨 100 倍採連乘：10,000 倍市值對應 1.5625 倍面積；中間值連續插值。共同基準只改整體尺度，不改個股相對比例。示意採 `g_ref = 50%`、`M_ref = 50 億元`，A（100%、5,000 億）、B（100%、50 億）、C（50%、500 億）得到 `5 : 4 : 1.118034`，約為 `5 : 4 : 1.12`；不為湊成精確 5:4:1 修改輸入或取整幾何。這是使用者指定的視覺偏好，不是回測驗證出的最優權重。

面積對 0、負值及缺資料必須有明確退化：只對正漲幅套用平方，不取負值平方偽裝上漲，也不把缺值當零。缺歷史市值不能默認係數 1；加權視角列為缺資料，可明示切換純漲幅視角查看。主上漲地圖之外保留「持平／回落／缺資料」入口；小標記的點擊區可擴大，但不能擴大其可見面積。若極端值使全圖失讀，使用放大／展開或明示的替代尺度，不能默默封頂。連續細胞排布須量測實際渲染面積比；有機造型、圓角及最小面積不能悄悄破壞公式。非圓形細胞的「直徑」指同面積圓的等效直徑。時間播放不得無提示逐日重新鋪滿畫面、掩蓋全體一起消長；尺度與縮放政策須明示。

畫面明細顯示原始漲幅、市值與日期、各項權重及最終面積權重；呈現契約記錄 encoding version、公式參數、共同基準及尺度。AI 使用原始數值與來源，策略的漲幅加權觸及率仍採線性正漲幅，不套用平方或市值係數，避免把視覺強調混成績效評分。

截至游標日的漲幅由共同區间的實際觀察計算。個股點選顯示起訖日期、有效交易日、原始與調整收盤、價格漲幅、現金股利口徑，以及截至當日的漲跌路徑；各自波段低點／最終峰值保留在明示的「事後波段」頁籤。未來峰值不能回灌日期場景。缺交易日、上市不足期間、長期停牌與異常資料保留原因，不能自動換較有利的起點。

原 catalog 僅提供事後飆股樣本，並非完整歷史可投資市場。第一版參與率的母體必須稱「所選目錄與區間中的合格機會」，不能直接稱全市場覆蓋率；未符合 catalog 規則的股票與完整市場母體另由有版本的契約提供。拖時間用於「當時畫面如何演變」；框選一段時間用於「期間有哪些機會、哪些已回落」，不能只看期末漲幅就漏掉中途大漲後回落的股票。

### 策略／ETF 是否把握住機會

同一股票、區間與來源版本下，並列三種不同問題：

1. **持有觸及率**：在機會區間內曾有可驗證成交持倉的股票數／合格機會數。只表示碰過，不能稱抓到主升段；ETF 披露快照只能形成快照觸及率，資料不完整時列出已確認與未知。
2. **機會加權觸及率**：以固定、同口徑的正價格漲幅作權重，檢查是否只碰到小漲股、錯過大漲股。這仍不等於賺到的比例；期間回顧若使用峰值／波段統計，須明示事後定義，不能與游標日同期漲幅混算。
3. **實際把握程度**：看成交進出、實際部位、持有時間與可歸屬損益。晚買、早賣或只買極小部位，即使觸及率高，也會從明細看出沒有賺到主要漲幅。可投資性的流動性、回落與執行成本另列，不與漲幅乘成不透明總分。

策略進場與行情起漲分開、訊號與成交分開、帳戶收益與股票上漲分開。ETF 只在披露快照所支持的日期標持有；快照空白不推成錯過，無歷史快照不推成零。比較面板保持同日期、同母體與同證據層級；來源不足的參與方不給假精確排名。

供 AI 使用的資料應為有版本的股票／episode／觀察區間／分類關係／价格觀察／參與證據記錄，包含來源 hash、計算定義、實際日期、可用時間及缺值原因，與畫面座標、主色、圓角完全獨立。AI 可取得完整機會清單與原始引用，不需看圖猜面積；新呈現方法消費同一份可追溯資料。

此輪唯讀來源查核確認原 v1 price/actions 快照仍在且 hash 相符；catalog 的永久 `SplitAdjustedClose` 可重用，但 `SignalClose` 的短期現金股利修正不適合歷史漲幅。尚未建立全市場日別投影、歷史市值或新的採用分數。三檔歷史例子只用來檢查端點與起點語意，不用來校準圖形大小、權重或接受門檻。

膜網是視覺風格，不能暗示真實地理疆界、互斥領土、市值占比或兩個業務族群實際合併。舊概念以生命周期股數及最小面積配置族群，不宣稱精確比例；新產品方向改依上節的共同期間、個股面積及參與契約，不能沿用舊大小卻改稱漲幅。參考圖中的「近期強弱」說明須有正式逐日量測後才能採用。多重歸屬、品質及未知資料按既有契約顯示。

切主題立即套用到全站，保留日期、選取、播放／暫停、捲動位置及證據，不觸發行情／研究重算。使用者偏好與 catalog／研究 selection 分開保存；正式前端建議本機 `research-web.preferences.v1`，正常重新開啟還原，未支援儲存仍能切換且不宣稱已保存。未知設定或偏好版本安全回到預設；原 catalog 換版不重設合法配色。帳戶同步不屬於此階段。

## 3. 網頁與 UX

### 策略圖鑑

每個方法用一段白話、一張規則流程、一張可追溯的結果摘要呈現。預設顯示研究狀態、適用市場、帳戶條件、期間、含成本結果與關鍵限制。保留失敗歷史，不以報酬最高作預設排序。

方法身分、規則版本、實驗 run 分開：同一方法可以有多版規則，同一版本可以有多個期間或情境。切換時保留選取的時間與股票，並在固定位置顯示當前版本、run 與條件。

### 回測工作台

同步查看帳戶價值、持股、現金、交易與重要事件；點曲線區間後，表格顯示該區間的記錄。主要結果以新台幣金額呈現，比例和專業指標作輔助。

帳戶從高峰跌了多少，與非命中嘗試累積損失分開顯示；股票事後大漲、策略辨認到機會、實際帳戶賺到大段報酬也分開。分配款已領到、尚未領到、未交付股權與模擬成交不能混成一個數字。

### 逐筆證據

每筆事件可固定定址。由交易列表開啟明細，檢查：當時可用的來源與時間、規則版本、觀察值／門檻、訊號、委託與成交、費稅、股數、前後現金、持股及原始文件。

後端回傳總筆數、游標與是否尚有下一頁，不沿用目前 2,000 筆上限卻無截斷提示的行為。未完成持倉、取消／未成交委託、配息與公司行動均可查，不能只有成功買賣。

### 研究歷程

呈現假說、預先登記的判斷規則、測試、淘汰、資料修正與後續驗證。歷史任務依其原始 mission 判讀；新規則不回寫舊結論。「格式正確」「列出的檔案 hash 已核對」「收支已對帳」「結果足以採用」是不同狀態，避免一枚綠色勾勾概括全部。

### 事件回放

手動拖動時間軸，或明確點播放。可停、可前後逐步、可直接跳到事件；動態效果可關閉，並遵守系統減少動態設定。畫面只在已保存的資料範圍內動作；沒有決策快照時仍可回放收支，理由區顯示缺少。[W3C 動態效果指引](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions)

同一時間控制連動圖表、現金、持倉、事件與證據，但不自動重新運算策略。播放速度是展示選項，不改研究資料。

## 4. 飆股時光圖

### 既有全市場原型的資料行為

以下記錄已完成的族群生命周期概念及其來源約束。最新個股機會版圖方向見第 1 節；正式接入將替換其面積／標籤規則，保留全市場直接探索、資料身份與證據操作，不把以下舊計數圖當成已完成的漲幅圖。

桌面以市場地圖為主，時間軸控制整個畫面；族群和個股由所選日期的資料自行出現。主圖是共用細胞壁、彼此貼合的膜網版圖，空間代表展示關係與狀態，不使用假的國家疆界。相同節點跨日期保留身分，膜會推擠、擴張、收縮與破裂；右側顯示近期新浮現、轉過峰值、確認退場的個股，點任何勢力或股票才開來源明細。手機依序堆疊，操作不依賴 hover。

核心操作是：**拖日期 → 勢力自行交替 → 點族群或個股 → 查日期／證據 → 看策略／ETF 參與**。沒有族群先決篩選。點勢力只展開明細，不切掉其他勢力；拖到新日期時，明細跟著更新，該勢力退場也保留選取並說明狀態。

- 初始探索整份已允許的 catalog，不能只輪播記憶體、貨櫃等手選案例。範圍從 2019-01-02 到 2026-08-14；歷史強權是互動比喻，不代表目前有 2000 年以前股價。沒有覆蓋的年份明示無資料。
- 個股生命周期以已存的達低點＋25%、翻倍門檻、峰值與回落確認日期作界線；確認日退場。峰值到確認日仍保留為「已過峰值」，不畫成當日必定下跌。沒有確認日的 21 段截至觀察截止仍未結束，不能動畫成消亡；7 段品質旗標隔離並保留證據。
- 同一股票可有多個 episode；個股節點及全市場股數按 security_id 去重，保留所有 episode refs。族群的上升區間股數隨時間變化，帶動膜邊界與視覺權重；全群只剩過峰值個股時從主膜網分離並移入退場帶。未保存的每日價格或強度不做平滑插值。
- 研究細群可從 parent_id 推導 25 個根，點開後再展開子群。沒有研究群的股票可由官方產業補充層／官方鏈或未知分類入口浮現；不因缺分類被藏掉。官方產業、官方鏈、研究群是不同來源層，明示區別。原 123 檔缺價值鏈分類者若有官方產業大類，仍保持細分類待補狀態。
- 160 檔跨多個研究根群，分類不是互斥領土。父子會員不能累加；群內股數各自去重，全市場股數只計一次，不能把圈圈數字相加。多重歸屬由關係與明細呈現，不硬指派唯一陣營。
- 可手動拖曳、往前／後逐步或點播放；不自動播放、不循環。所選日期的數字立即顯示；幾何膜網在前後場景間過渡，不把中間動畫幀當成行情觀測。快速拖曳從當前形狀延續，取消舊動作；播放可暫停。減少動態直接切到最終版圖，省略融合／破裂效果。播放不重算研究。
- 證據明細保留來源版本、原始日期、口徑、分類／品質與缺值。工程欄位收在來源區；主地圖以族群、股票、日期與白話狀態呈現。

### 「勢力」的資料依據

**目前資料能支援波段興衰回顧，尚未支援每日強弱排名。** 概念區塊的視覺權重隨「達＋25%後至自身峰值之間的獨立股票數」變化，另保留最小可見面積；過峰值者另列。這是已選出的事後樣本在所選日期的狀態，不稱當時最強、最佳買點、市場占比或族群當日報酬。動畫的幾何位置、面積與泡泡融合不冒充金融指標或業務族群合併。

正式「當日強權」可後續接版本化的相對市場強度、市場廣度、量能或其他已核准量測；先固定指標、視窗、母體、分群時間、正規化及缺值口徑，再建立保存的逐日證據。每種地圖顯示其強度依據，不讓 renderer 或 agent 為了動畫自行發明分數。整波最終倍數、wave 的長窗口與 winner 不能代替某日強弱。

### 點進去後：族群比較與個股日期

原族群研究桌作第二層：wave 橫條表示最早低點至最晚高點的共同窗口，每股日期分開；長窗口顯示實際天數，不能為了畫面短而改切歷史產物。短波 v2 是獨立研究。

同期表並列期末漲幅、峰值漲幅與各股峰值日，區別自身 episode 報酬。`winner_security_id` 稱「共同窗口峰值漲幅最大」；`earliest_qualifying_25pct` 稱「翻倍成員中最早達低點＋25%」。兩者不統稱龍頭，也不作全市場逐日勢力排名。隔離／不可比較仍可查，但不參與排名。

### 回顧與可知時間

**第一版只開「事後看行情」。** 可以拖到過去某天看 episode 交集；這是對今日已建置目錄的切片，包含之後才確認的低點與峰值。若以 `qualification_date` 控制節點浮現，名稱是「依本次調整資料的翻倍門檻日」，仍不能稱當時已知訊號。

未來接到真實 PIT 資料與來源可用時間後才啟用「當時可知」。目前 adapter 固定 `label_kind=retrospective`、`label_available_at=null`、`missing_reason=not_pit_reconstructed`；不能把低點日、＋25% 日、翻倍日或 catalog 建置時間填成歷史標籤可用時間。

股票節點的大小若編碼漲幅或成交額，要標出其期間／單位；不以大小代表策略品質。相同股票可以有不同 episode，不能以代號合併。已確認業務角色與待核實關聯分開；未知歷史角色不沿用今日分類。

### 策略與 ETF 的參與層

點股票後保留一個參與欄：研究 run 的訊號、委託、成交、持有區間、部位與可歸屬收益，以及 ETF 官方披露快照。現在 catalog 尚未接入這些資料，第一版明示「尚未接入」，不以範例冒充真實持股。資料齊全後，時間軸增加分開的證據軌，不改原分類表。

這些結構有助於分辨「根本沒看到」「看到但未成交」「部位太小」「過早賣出」「ETF 在披露時持有」。可用同一套定義比較不同 run 的覆蓋、延遲與收益來源，找出下一個有理由研究的問題。

但觀察到股票大漲後再設計過濾條件，仍是已看過結果的探索。飆股定義、觀察期限、價格政策、episode 分界與下一輪判斷要先登記；介面不能把診斷標成獨立驗證。不得拖動時間即解封未知期間，也不得先把封存資料送到瀏覽器再用 CSS 隱藏。

## 5. ETF 方法庫與公平比較

本次官方來源盤點見 [ETF 比較研究](etf-benchmark-research.md)。0050、0052、00981A、VOO、QQQM、SMH 是不同角色的初始研究名單，不是完整市場的績效排行榜。

ETF 頁面呈現：成立時間、上市市場與基金註冊地、實際曝險、市值／產業／動能等方法、被動或主動、公開規則、調整頻率、費用、集中度、當期／歷史持股與資料日期。指數規則可以研究，主動管理公開說明通常不能重建經理人的完整決策。

三種比較明確分開：

1. 發行商公開的 ETF 歷史績效，附原始口徑與日期。
2. 相同資本、日期、可執行交易與幣別政策下，持有 ETF 的帳戶情境；需要另外建立可核對資料與運算，不能從宣傳數字直接變換。
3. 借用公開方法但調整持股／權重的研究候選；這是新策略，不能冠用原 ETF 績效。

比較契約涵蓋同起訖期間、原幣／台幣、匯率時間與來源、配息再投入、累積／年化、淨值／交易價格、基金內含費用與投資人額外成本、稅務假設、可投資起日、停牌與交易日曆。沒有對齊時展示來源資料而不排名、不畫成同一條可比曲線。

基準至少包括廣泛市場及符合候選曝險的產業／風格 ETF，避免把科技集中與大盤的差別全稱為選股能力。若使用績效篩選 ETF，保存事先固定的範圍與期間，保留新成立、下市／合併或資料缺少基金，揭露存活者和勝者挑選偏差。

### 法規假說的查證

「ETF 都只能持有每檔 10%，拿掉限制就會更好」不能作預設事實。

- 台灣基金管理辦法第 35、41 條對符合指數組成的 ETF 有例外，超過 10% 時仍受相應指數權重等條件約束。[基金管理辦法](https://law.fsc.gov.tw/LawContent.aspx?id=FL032788)
- 2026-04-24 的令，對以國內股票為限的股票型基金及主動 ETF，符合上市股票在加權指數比重逾 10% 等條件時允許例外；仍不得超過該指數比重，且該公司股票加計相關債券以基金淨資產 25% 為限。不能概括為任意股票都可 25%。[金管會當期令](https://law.fsc.gov.tw/LawContent.aspx?id=GL004263)
- 美國 SEC 的說明區分基金資產占比與發行公司表決權占比，以及 diversified/non-diversified；其中「10%」並非所有 ETF 每檔基金權重上限。逐檔仍須核對現行公開說明書、稅制與指數規則。[SEC 分散限制說明](https://www.sec.gov/files/staff-report-threshold-limits-diversified-funds.pdf)

放寬權重可能同時放大報酬、集中風險與回落，是可研究的假說，不是已證實的改進。本次未實驗該假說，也未改飆股研究的持股限制或採用門檻。

大型行情、每日持股快照與重建 cache 不放入前端包或一般 Git，也不混入研究任務源碼。ETF acquisition 是否適合既有 submodule，實作前須檢查其現有接口與市場範圍；本次只規劃責任邊界。

API 與資料呈現契約可以重做。舊 API 的合理資料保護邊界保留，但它的任務發現、欄位、上限與回應型別不必沿用。研究執行仍由明確核准的任務入口控制；展示互動不暗中啟動研究、下載或修改證據。

## 7. 可擴充，但維持共同 UX

### 證據與呈現分層

`原始任務產物 → 按 schema 的唯讀 adapter → 版本化展示契約 → renderer → 網頁`

adapter 保留 source schema、run 身分、單位、缺值、原始／衍生狀態與每個欄位的來源。舊結果保持可讀，新類型透過顯式 adapter 接入，不要求每份歷史產物改成新 schema。

展示索引可重建，不能成為另一個偷偷修正原始結果的真相來源。大型產物的內容定址索引需包含來源 hash，若索引與原始證據不符，要顯示過期並停止使用相應投影。

### Agent 的呈現入口

agent 提供版本化 `presentation_manifest`（本提案命名，尚未實作），由共用 renderer 顯示。可組合 time series、事件時間軸、表格、規則圖、heatmap、股票節點、收益來源與對照矩陣。每個 block 聲明資料引用、單位、語義、來源鏈、適用能力、選取連動與空值狀態。

agent 可提出新視覺方法，但不能自行改全站導航、重新計算正式指標或把自由文字理由當原始證據。先用現有 block 組合；確實不足時新增有版本的 React renderer、輸入契約、固定 UX 行為與退化表格，一次接好，各任務重用。

不把任意 agent HTML/JS 直接載入可信任 app。未知 block 不使整頁崩潰：顯示類型、來源與「尚未支援」，以表格／原始結構檢視退化。缺資料、讀取失敗、schema 不支援與尚未核對是不同狀態。

### 狀態與導航

研究頁可定址到 `/strategies/<id>/versions/<id>/runs/<id>`，事件以明確 run＋event/attempt ID 定址；時間、比較對象、排序與頁碼放可分享的 URL query。重新整理與返回恢復位置。ETF 以基金身分定址，上市 ticker 不等同基金或股票身分。

全市場入口為 `/market/catalogs/<sha>?at=<date>`，不要求 group。深連結以 `(schema_version, manifest_canonical_sha256, entity_type, entity_id)` 定址；展開同窗口可到 `/market/catalogs/<sha>/waves/<wave_id>?at=<date>`。同一 ID 在改名或品質修正後可能保留而內容改變，不能只用 run_id／wave_id 命中快取；舊連結顯示原產物及修正關聯。官方節點用 `chain_code + node_code`，不能只用 node_code；`TW:code` 的歷史代碼重用仍是尚未解決的來源限制。

展示索引保存全市場生命周期事件與分類邊；server 依允許範圍按日期回傳場景及證據游標。日期、來源版本與量測口徑為 cache 身分，群與股票選取只影響明細。相鄰場景保留節點 ID，圖形重排不能產生新股票或假裝退場。效能所需的顯示層級／標籤隱藏與真實無資料分開，完整清單可查；不能因移出畫面就宣稱勢力消亡。

角色補證另以 schema／packet canonical SHA 綁定 catalog 與展示結果，assertion deep link 包含該 packet 身分；packet_id 或 assertion_id 單獨不足。補證未載入、切換版本與日期請求不能串用 cache。這個可選層提供理解／證據，預設原市場節點及生命周期不因最新補證重分群或改日期。

圖表與表格共用一個 selection context；只保存選取 ID、時間與顯示設定，其餘從資料推導，不在各分頁保存重複帳戶真相。舊請求取消，並核對 response 的 run/request 身分，避免快速切換時把 A 的結果顯示在 B。[React 狀態設計](https://react.dev/learn/choosing-the-state-structure)

### 邊界與效能

列表只查 catalog；使用者選到已允許的 run，才載入相應資料。價格、持股與大型交易記錄按時間／游標查詢；細節按點擊讀取。圖表降採樣只影響顯示，點查與匯出仍取精確資料。禁止將完整市場 cache 打包到瀏覽器。

網站的可見範圍在 server/catalog 層強制；封存、未知授權或未完成的內容不預先下載。輸出保留 source as_of 與 available_at；歷史來源缺失不默換當前 cache。

固定共用 spacing、typography、色彩語義、表格操作、loading/error/empty states。新 renderer 接入相同鍵盤、觸控與減少動態能力；不以每個研究各自的一套 CSS 維護 UX。

`src/design-system/` 擁有配色 preset、深淺 token 及狀態語意，`src/app/` 管理偏好還原與頂欄設定；各功能與 renderer 消費同一套 token。主題不是研究 schema／資料 cache 身分，不因換色產生新回測或資料副本。新增配色須驗證文字、選取、圖例與警告在實際表面上的對比；維持鍵盤焦點、觸控與減少動態支援。

膜網 renderer 建議放在 `src/visualizations/foam-atlas/`：純幾何排布、動效控制、可點選標籤分開；scene adapter 提供固定日期的族群／股票身分、計數與證據。幾何只處理視覺權重、可見面積與畫面尺寸，動效只處理進場／退場、取消舊過渡及減少動態；二者不查價格或決定研究狀態。選取／切色不重新求解版圖；日期或尺寸改變才重新配置。未來 AI agent 經 renderer registry 提供有版本的量測與呈現選項，仍共用此互動與主題系統。
