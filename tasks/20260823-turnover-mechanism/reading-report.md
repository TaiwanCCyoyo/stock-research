# 動能股至少抱二十個交易日，換手減少而選股差距大致保留

在這次比較中，動能前十名加上至少持有二十個交易日，每個部位的年換手由 16.08 降至 9.28 次，仍保留約 94% 相對隨機組的報酬差距；這是唯一通過四項條件的設定。

比較期間：訓練 2019-01-02 至 2023-12-31；驗證 2024-01-01 至 2026-08-14。

報酬差距採部位報酬加總，並非複利帳戶收益；同一驗證期間已在前面研究中使用，這次沒有新增未見資料。

## 同樣的排名，改三種減少換手的方法

研究原問：讓持股少換幾次，排名選股相對隨機挑選的優勢還能保留多少？[排序與隨機選股研究](../20260823-selection-vs-random/report.md) 提供三個基準：近期漲幅排名、加入同群走勢，以及全部特徵合併。

本次分別放寬排名退出範圍、增加最短持有時間，或把每日分數先取數日平均。最短持有二十個交易日，是約一個交易月內不因排名下滑退出；喪失股票池資格仍可觸發退出。每個原基準測八種設定，共 24 個驗證設定。

訓練期 2019-01-02 至 2023-12-31，驗證期 2024-01-01 至 2026-08-14；共用初始 1,000 萬元資金。隨機組與策略同日買進、持有相同期間。

## 換手少了，兩邊都受惠

| 驗證期動能十檔         |      原持有規則 | 至少持有二十個交易日 |
| ---------------------- | --------------: | -------------------: |
| 每個部位每年完整換手   |        16.08 次 |              9.28 次 |
| 策略部位加總報酬       |         +92.35% |              +97.50% |
| 隨機組平均部位加總報酬 |         +36.30% |              +45.07% |
| 策略減隨機組的差距     | +56.05 個百分點 |      +52.42 個百分點 |

「保留 94%」指最後一列的差距比值，並不是保留 94% 本金。部位加總報酬把每筆報酬按配置名額平均後累加；表內數值按原表四捨五入。減少換手讓策略與隨機組都少付成本，所以策略總報酬上升的同時，兩者差距略縮小。

原定成本估計使用每趟 0.5%，換手上限為每部位每年十二趟。以初始 100 元作示例，十二趟的估計成本是 6 元；這是門檻的估算法，與引擎逐筆費用另有口徑。放寬排名區間或平滑分數的其他設定，沒有同時保住原要求。
