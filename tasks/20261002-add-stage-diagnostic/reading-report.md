# 未被列為捕捉到大漲的持股中，沒有加碼的一組合計虧錢

閱讀整理：2026-11-04。

**2019–2023 年原時點和延遲一天帳戶中，已結束且未被列為捕捉到大漲的持股，有實際加碼的一組合計賺錢，沒有加碼的一組合計虧錢；延遲後，前一組少賺很多。**

分組是在持股結束後，依有沒有真的加碼決定；兩組股票和持有過程不同，尚未分離出加碼本身多賺或少賺多少。

研究問題：非命中損益主要來自已加碼或未加碼的嘗試？延遲路徑為何惡化？

## 比較的是哪些股票與時點

研究重讀 2019–2023 年兩個帳戶：照原時點執行，以及所有交易多等一個交易日。每日帳戶有 303 次持股嘗試，延遲帳戶有 204 次，期末各有 4 次、3 次尚未結束，這些不列入非命中或虧損組。每次從首次買入到結束算一段，再按這段期間有沒有真的加碼成交分組；加碼單未成交歸在沒有加碼組。

表內「非命中」沿用原報告分類，指已結束、但沒有被列為捕捉到大漲的持股嘗試，包括小賺與虧損；其淨現金是這一組收支的合計。委託次數包含沒有成交的單，操作晚數是一晚有工作就計一次。

## 延遲後，有加碼組的正現金大幅減少

| 完成非命中淨現金（元） |      實際加碼 |      未加碼 |
| ---------------------- | ------------: | ----------: |
| 每日                   | +1,218,574.94 | -822,140.46 |
| 延遲一天               |   +144,842.00 | -598,880.46 |

加碼成交由 99／106 次提案降至 33／79。延遲組惡化主要來自已加碼組正現金減少；現金、數量與成員同時改變，不能當配對因果效果。

## 這次回答到哪裡

結果把問題分成兩條：首次買入的品質，以及符合加碼條件卻沒有買到。延遲帳戶有 46 次加碼未成交，但詳細原因未保存，無法判定其中多少由現金不足或漲停造成。
