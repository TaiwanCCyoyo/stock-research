# 加碼階段診斷：損失不只發生在加碼後

閱讀版更新：2026-11-02。這是保存證據的閱讀整理；可讀不等於策略通過或擁有者驗收。

## 問題與答案

非命中損益主要來自已加碼或未加碼的嘗試？延遲路徑為何惡化？

**兩條保存路徑中，有實際加碼成交的非命中組淨現金為正，未加碼組為負；不能據此認定加碼造成獲利。**

## 實際比較

2019–2023 已暴露期間；重讀每日 303 次、延遲 204 次原生嘗試，含各 4／3 次未結束。每組計整個生命週期，不切成加碼前後。

## 結果與分母

| 完成非命中淨現金（元） |      實際加碼 |      未加碼 |
| ---------------------- | ------------: | ----------: |
| 每日                   | +1,218,574.94 | -822,140.46 |
| 延遲一天               |   +144,842.00 | -598,880.46 |

加碼成交由 99／106 次提案降至 33／79。延遲組惡化主要來自已加碼組正現金減少；現金、數量與成員同時改變，不能當配對因果效果。

## 後續結果與修正

後續一次重試的正常路徑僅多賺 34,908 元，尚無延遲修復證據。原延遲帳戶、零損益錨點退出及 ret60 上限的失敗判斷維持。

## 能支持的決定與未回答部分

支持分開研究初始試單品質與未成交加碼如何處理；不支持拿事後加碼資格當進場訊號。原延遲中 46 次未成交加碼的詳細原因未保存，不能猜測全由現金或漲停造成。

**主要限制：這是事後依實際成交分組的整段嘗試歸因，不是隨機對照、加碼增量損益或新策略回測。**
