# 多延遲一個交易日：獲利保留未達固定要求

閱讀版更新：2026-11-02。這是保存證據的閱讀整理；可讀不等於策略通過或擁有者驗收。

## 問題與答案

一張進場候選若所有交易多延遲一日，是否仍保留足夠淨利？

**延遲帳戶只保留每日對照 52.90% 淨利，未達原定 70%，不能作為已可採用的候選。**

## 實際比較

2019–2023，初始 200 萬、最多五檔。比較兩個安靜期末建議日的配對基準與多一日延遲；不是較早單安靜日結果。v4 才是完整可判讀執行。

## 結果與分母

| 指標                     |     配對每日 |     延遲一日 |
| ------------------------ | -----------: | -----------: |
| 淨利（元）               | 2,934,085.15 | 1,552,078.87 |
| 完成非命中淨現金（元）   |  +396,434.48 |  -454,038.46 |
| 委託／操作晚數           |     714／549 |     978／692 |
| 完成命中／非命中／未結束 |    6／293／4 |   13／188／3 |

保留率分母是正淨利，不是期末資產。命中數更多仍不代表收益更高；較少成交但更多委託也是模型結果。

## 後續結果與修正

v1–v3 的失敗／部分執行不當成經濟結論。後續加碼診斷及一次正常重試沒有證明延遲已修復；正常重試僅增加 34,908 元。

## 能支持的決定與未回答部分

支持不把此候選推到採用或獨立確認；需要另外明訂處理時點與未成交加碼的假設。未完成最終 owner 損失預算，非命中歸因也不等於帳戶回撤。

**主要限制：這是固定執行模型下的全體延遲情境，不等於所有真實缺席方式；仍非獨立或前瞻證據。**
