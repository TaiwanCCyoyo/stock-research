# 所有交易晚一天，淨利只剩原來約一半

閱讀整理：2026-11-04。

**所有交易多等一個交易日，淨利由 293.41 萬元降至 155.21 萬元，只保留 52.90%，低於原定 70%。**

這裡把每筆交易都延遲一天，與偶爾缺席的情況不同；資料仍是已看過的 2019–2023 年。

研究問題：一張進場候選若所有交易多延遲一日，是否仍保留足夠淨利？

## 比較的是哪些股票與時點

2019–2023 年，以 200 萬元、最多五檔、首次買一張的帳戶，測試每筆交易都額外延遲一個交易日。例：原本星期二執行，改成下一個交易日；遇休市不按日曆天計。兩邊採同一期末安排，保留兩個不新增建議的交易日；完整結果採第四版。

表內「非命中」沿用原報告分類，指已結束、但沒有被列為捕捉到大漲的持股嘗試，包括小賺與虧損；其淨現金是這一組收支的合計。委託次數包含沒有成交的單，操作晚數是一晚有工作就計一次。

## 淨利保留 52.90%，低於原定 70%

| 指標                     |     配對每日 |     延遲一日 |
| ------------------------ | -----------: | -----------: |
| 淨利（元）               | 2,934,085.15 | 1,552,078.87 |
| 完成非命中淨現金（元）   |  +396,434.48 |  -454,038.46 |
| 委託／操作晚數           |     714／549 |     978／692 |
| 完成命中／非命中／未結束 |    6／293／4 |   13／188／3 |

保留率分母是正淨利，不是期末資產。命中數更多仍不代表收益更高；較少成交但更多委託也是模型結果。

## 這份結果和後續研究的關係

v1–v3 的失敗／部分執行不當成經濟結論。後續[加碼診斷](../20261002-add-stage-diagnostic/report.md)及[一次重試](../20261002-add-retry/execution-normal-v1.md)沒有證明延遲已修復；正常重試僅增加 34,908 元。

## 這次回答到哪裡

這個候選對執行時點很敏感，未達事前要求。延遲下的未成交加碼與重新進場，是保存結果指向的後續問題；使用者最終可承受的損失上限尚未定案。
