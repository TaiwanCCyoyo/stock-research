# 早期加碼訊號：五個觀察量沒有通過本次篩選

閱讀版更新：2026-11-02。以下整理保存的研究與後續更正，未重跑市場計算。

## 原本的問題

股票反覆符合條件時多配置資金，能否在加碼當下辨認後來較會上漲的持股？

## 目前能回答的事

五個價格／排名觀察量在兩個決策點都未通過既定條件；這次沒有建立可採用的早期加碼訊號，也沒有執行加碼帳戶回測。

## 實際比較

第一輪在進場後第20根K棒，修訂後加測第2根，並將退化的連續在榜天數改為期間內在榜天數，回到owner「連續符合就多佔位置」的問題。修訂與第一輪已看過的結果保留在mission第9節，不宣稱兩輪都是全新資訊。

比較進場後漲跌、當日排名、月線距離、在前30名天數、週線密集，以及一個代號雜訊控制。原文常寫六個候選；實際是五個有經濟含義的量加一個控制。

主要量是未來120根K內「曾漲50%比例減曾跌33.3%比例」，不是帳戶獲利。

| 決策點  | 可用部位／股票／進場月份 | 結果               |
| ------- | ------------------------ | ------------------ |
| 第2根K  | 1350／629／50            | 五個觀察量均不通過 |
| 第20根K | 1325／621／49            | 五個觀察量均不通過 |

第2根K的在榜天數價差為0.138，但每股只留第一筆後降至0.037，低於0.05要求。代號控制的去重複價差0.117雖大，原價差只有0.033，沒有通過完整門檻；不能單看一欄宣稱控制通過或以單一控制確定普遍「雜訊地板」。

## 尚未回答與決策意義

原問題只被回答到訊號篩選層，沒有實際分配額外資金、現金競爭、單檔上限與加碼後損益。部位數不是獨立樣本數，五年約只有十個不重疊120日區間。

後續最低持有期研究發現移除20日下限並未在該30檔訓練比較改善報酬與回落，修正本卡「下限只是延後砍輸家」的猜想。後續等風險研究另問不用辨認贏家時如何配置，不能把本卡的負面篩選當成部位大小整條方向已結束。

## 閱讀界線

本卡使用既有30檔訓練期持倉，觀察窗口高度重疊；沒有獨立樣本確認，也未涵蓋所有加碼方式或部位配置方法。

原始研究判定仍保留；這份閱讀版可供理解與討論，不代表策略獲准或新增獨立驗證。
