# 重複上榜沒有形成穩定的早期加碼訊號

閱讀版更新：2026-11-04。數字沿用下列保存來源。

**研究問題：** 股票反覆符合條件時多配置資金，能否在加碼當下辨認後來較會上漲的持股？

既有三十檔模型的訓練期持倉中，進場後第 2 與第 20 個交易日，按進場後漲跌、當日排名、距月線遠近、上榜天數及週均線密集程度分組，都未穩定分出後來較常大漲、較少大跌的部位。完整日曆起訖未保存，且沒有計算實際加碼後的帳戶損益。

**主要限制：** 本卡使用既有30檔訓練期持倉，觀察窗口高度重疊；沒有獨立樣本確認，也未涵蓋所有加碼方式或部位配置方法。

[週線結構研究](../20260905-weekly-structure/report.md)提供其中一項均線密集指標；本篇改問已買進的持股何時值得增加資金。後續[最低持有期研究](../20260905-min-hold/report.md)另測等待天數，[等風險配置](../20260906-equal-risk-sizing/report.md)另測投入金額。

## 實際比較

一個「部位」是一次買進形成的持倉，同一檔股票可重複出現；這裡一根日 K 棒代表一個交易日。先在買進後第 2 或第 20 日觀察當下條件，再從該決策日往後看 120 個交易日的價格。

「兩端命中差」以該組可評估部位為分母，計算曾漲 50% 的比例減去曾跌約 33.3% 的比例。假設決策日價格 100 元，就是比較後面曾到 150 元與曾到約 66.7 元的比例；同一部位可能兩邊都碰到，因此不是把贏家與輸家分成互斥兩組。

資料期間：保存的本任務 mission 與 report 僅稱訓練期，未列出完整日曆起訖；本文不以任務日期補成資料期間。

第一輪在進場後第20根K棒，修訂後加測第2根，並將退化的連續在榜天數改為期間內在榜天數，回到研究委託人「連續符合就多佔位置」的問題。修訂與第一輪已看過的結果保留在mission第9節，不宣稱兩輪都是全新資訊。

比較進場後漲跌、當日排名、月線距離、在前30名天數、週均線彼此接近的程度，以及一個僅由股票代號產生、不含價格資訊的雜訊對照。原文常寫六個候選；實際是五個有經濟含義的量加一個控制。

主要量是未來120根K內「曾漲50%比例減曾跌33.3%比例」，不是帳戶獲利。

| 決策點  | 可用部位／股票／進場月份 | 結果               |
| ------- | ------------------------ | ------------------ |
| 第2根K  | 1350／629／50            | 五個觀察量均不通過 |
| 第20根K | 1325／621／49            | 五個觀察量均不通過 |

第 2 日依在榜天數分組，最高與最低組的兩端命中差相差 0.138（13.8 個百分點）；每檔股票只留第一筆後，差距縮為 0.037（3.7 個百分點），低於去重後至少 5 個百分點的要求。代號控制的去重複價差0.117雖大，原價差只有0.033，沒有通過完整門檻；不能單看一欄宣稱控制通過或以單一控制確定普遍「雜訊地板」。

## 這次還沒有回答什麼

原問題只被回答到訊號篩選層，沒有實際分配額外資金、現金競爭、單檔上限與加碼後損益。部位數不是獨立樣本數，五年約只有十個不重疊120日區間。

後續最低持有期研究發現移除20日下限並未在該30檔訓練比較改善報酬與回落，修正本卡「下限只是延後砍輸家」的猜想。後續等風險研究另問不用辨認贏家時如何配置，不能把本卡的負面篩選當成部位大小整條方向已結束。
