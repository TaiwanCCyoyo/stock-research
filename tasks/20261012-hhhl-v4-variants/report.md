# HHHL v4 條件與後續翻倍：描述研究 v1

高過高事件與後續翻倍有可描述的關聯，但本版沒有顯示它比新高量能事件更強。全部原合格事件的翻倍率，在 126／252 個交易日內分別為 **7.81%／15.97%**；一般合格股票日為 5.66%／14.06%，新高量能控制為 8.25%／16.90%。這些都是事件比例，不能解讀成「多少股票必然成為飆股」。

未翻倍事件確實常見支撐失效。252 日內，72.32% 曾跌破 Z2，49.97% 曾跌破 restart low；但最後翻倍的事件也有 25.13%／10.56% 在首次翻倍前觸發。這提供未來停損研究的可查素材，尚未計算停損的交易效果。

固定計算與驗證已完成。完整 159,609 列彙總、逐筆版本、共用定義與查詢入口均已保留；[數字附錄](result-tables-v1.md)、[資料契約](data-contract.md)、[驗證收據](verification-v1.json)可供其他 session 直接參考。交付 PR #9；merge 仍由 owner 決定。

## 分母、期間與資料

原 v4 合格事件共 **51,731 筆、1,864 檔股票**。其中 1,819 檔有多筆事件；每股事件數中位數 30、90 百分位 43、最大 54。共同日曆涵蓋 2019-01-02 至 2026-08-14，共 1,849 日；價格、因子與 v4 輸入使用 [固定 pins](params/input-pins-v1.json)。沒有新增下載或重新偵測 v4。

## 固定條件與候選

開發半 H126 在 66 個可選原子區間中，有 64 個符合事前的 300 已知事件／60 股票門檻。按固定 exact-rate 排序、每族取一條，得到下列五項。全部十個 pair 與一個固定 triple 均保留，共 16 個候選；K 族仍只作診斷。沒有事後追加參數搜尋、及格門檻或用另一半重新選擇。

| 固定順序 | 條件                                 | H126 開發／另一半翻倍率 | H252 開發／另一半翻倍率 |
| -------- | ------------------------------------ | ----------------------- | ----------------------- |
| 1        | C3：收盤 ≥ 1.6 × MA240               | 18.01%／17.17%          | 22.85%／21.40%          |
| 2        | D2：收盤 ≥ 2.5 × 過去 250 日最低收盤 | 17.85%／16.44%          | 22.66%／21.80%          |
| 3        | G：凍結 v4 量比 < 1.5                | 17.63%／19.08%          | 23.04%／21.78%          |
| 4        | H：過去 120 日報酬排名 ≥ 90 百分位   | 15.40%／13.29%          | 22.23%／20.52%          |
| 5        | B：收盤 ≥ 1.2 × Z2                   | 14.62%／15.29%          | 21.65%／21.57%          |

強勢價位條件有較高的原始翻倍率，同條件控制通常也提高。例如 C3 的 H252 另一半為 21.40%，同條件 C-nh 為 22.04%；固定 triple C3＆D2＆H 的 H252 另一半為 22.75%，同條件 C-nh 為 23.15%。因此不能把篩選後提高的比例全歸功於 HHHL。

G < 1.5 的同條件 C-nh／C-52w 沒有已知樣本，率為 null；不能宣稱優於控制。B 是型態專屬條件，控制沒有相應 Z2，所以使用**未加條件**的控制，`reference_kind` 明列此差別。條件群的賠錢率也不低：上述五項 H252 約 48.8%～58.5%。全部候選的樣本、股票數、控制率、未知、截尾、小樣本與高賠錢率註記都在完整 summary，附錄按固定順序列出，不只保留高率結果。

## 支撐與型態失效素材

下表使用全部完整日曆且結局已知的 P-all；nonhit 觀察完整 H，hit 僅觀察**嚴格早於首次翻倍**的旗標。右欄是若以該訊號研究停損時，可能先碰到的最終翻倍事件比例，並非實際停損績效。

| 訊號                                | H126 nonhit／hit 觸發 | H252 nonhit／hit 觸發 |
| ----------------------------------- | --------------------- | --------------------- |
| X2：收盤跌破 Z2                     | 58.78%／14.15%        | 72.32%／25.13%        |
| X3：收盤跌破 restart low            | 34.01%／3.68%         | 49.97%／10.56%        |
| X4：確認低點低於 Z2                 | 62.82%／17.02%        | 75.49%／29.42%        |
| X5：收盤跌破 MA20                   | 100.00%／84.32%       | 100.00%／92.11%       |
| X5：收盤跌破 MA60                   | 98.26%／45.63%        | 99.96%／72.90%        |
| X6：收盤 ≤ 起點 90%（跌幅至少 10%） | 57.74%／20.72%        | 70.15%／29.29%        |
| X6：收盤 ≤ 起點 85%（跌幅至少 15%） | 43.26%／10.86%        | 58.30%／17.72%        |

MA20 在此完整窗口覆蓋全部 nonhit，但也觸及絕大多數最終 hit；單看失敗覆蓋率不足以選停損。X1 上方線、以上八個旗標的所有 L5／10／20／40 與完整 H、觸發報酬分位數、unknown 和上下界均在 summary。此 reverse 分母內旗標 unknown 實測為零，**不代表全資料沒有缺價**：前述結局 unknown 仍完整保留。

固定 L20／H252 的 X2 例子：nonhit 在前 20 日觸發率 22.86%；最終 hit 的 strict-pre-hit 代價為 11.30%。另一張新 riskset 表只保留 t0..L20 可觀察且尚未翻倍的事件，跌破支撐仍保留：triggered 群最終翻倍 735／8,557（8.59%），all-false 群 5,647／32,042（17.62%）。這個差異含當下報酬差異，不能直接稱為旗標的額外預測效果。

附錄因此也列相同 L20 報酬層。起點以下層的 triggered／all-false 翻倍率為 7.93%／11.00%；上漲 10%～25% 層反而是 33.33%／26.14%，但 triggered 只有 93 個已知事件。各層小樣本與反向結果都保留，沒有從中改選停損規則。舊 active／上方線表另存，不能與新 riskset 混合。

## 年度、近高與解讀限制

刪除 P-all hit 最多的 2020 起點年後，H126 開發／另一半翻倍率為 7.44%／6.78%；H252 為 14.20%／13.13%。全部候選的年度與刪最好年表保留各半；候選各自移除的年可能不同，控制移除**同一目標年**，不可把兩半或控制自行選出的不同年合併。2026 年 H252 沒有完整窗口，零分母率保留 null。

近高只是起點描述：P-clean 有 27,368 筆 D 已知、6,923 筆未知；其中 54.69% 的已知事件達到原指定近高基準（D≥1），包含未知的界為 43.65%～63.84%。這不是後續翻倍率，也不是策略證據。

同股多事件、窗口重疊與大量比較造成相依；兩半沿用同一已暴露市場期間，不能稱獨立驗證。資料包含 current-reference 因子／產業分類、現存 universe 與暖機範圍限制；不能把回溯描述當成完整 PIT 或可交易訊號。X4 沿用原 v4 1.5ATR 與缺價語義只復原確認日；新增 F／K 等特徵依共同日曆缺價後暖機，G 保留原量比語義，兩者不能混接。
