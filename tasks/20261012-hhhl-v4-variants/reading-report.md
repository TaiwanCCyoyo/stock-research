# HHHL 條件與失效訊號：有關聯，尚未證明型態增量

閱讀版更新：2026-11-02。這是保存證據的閱讀整理；可讀不等於策略通過或擁有者驗收。

## 問題與答案

哪些條件伴隨 HHHL 後續翻倍？未翻倍前常出現哪些失效訊號，會犧牲多少最終翻倍事件？

**HHHL 全事件翻倍率低於新高量能控制；支撐失效常見於未翻倍者，也會先出現在部分最終翻倍事件。**

## 實際比較

51,731 合格事件、1,864 檔；126／252 共用觀察，主分母只納完整日曆且結果已知。先翻倍後收低仍為 hit；loss 指未曾翻倍且末價低於起點。固定代碼分半共用同一市場，非獨立驗證。

## 結果與分母

| 組別             | H126 率／已知數 | H252 率／已知數 |
| ---------------- | --------------: | --------------: |
| P-all            |   7.81%／45,956 |  15.97%／40,720 |
| 新高量能 C-nh    |   8.25%／96,624 |  16.90%／85,118 |
| 250 日新高 C-52w |  10.60%／40,140 |  18.00%／36,224 |

H252 未翻倍者 72.32% 跌破 Z2，但最終翻倍者也有 25.13% 在第一次翻倍前觸發。主題是可能錯殺的素材，不是已模擬賣出。

## 後續結果與修正

原 mission 開頭仍是準備狀態；完整報告已記固定計算完成。網頁追加文字指出另一半 H252 可比較的 7 個候選均低於同條件 250 日新高；這項文字證據可讀，原 HTML 保留。前一 v4 的首次決定／截尾分母不同，率不可直接相減。

## 能支持的決定與未回答部分

可用來討論型態是否只重述強勢及失效訊號的代價。未完成停損、持股容量、成本或 owner 接受。條件強的控制也升高，不能把篩選後高率全算 HHHL 功勞。

**主要限制：這是事件與價格結果研究；條件篩選、支撐觸發與所謂賠錢率，都不是停損效果或帳戶績效。**
