# 頭頭高、底底高篩出強勢股，仍未勝過同條件的新高股

閱讀整理：2026-11-04。

**頭頭高、底底高事件的半年與一年翻倍比例，都低於兩個新高對照；跌破支撐常見於未翻倍者，也曾出現在最終翻倍者身上。**

各組沿用同一段歷史；支撐跌破是價格過程的紀錄，沒有模擬當時賣出後的帳戶結果。

研究問題：哪些條件伴隨頭頭高、底底高突破後翻倍？未翻倍者常出現哪些支撐失效訊號，最終翻倍者中又多少曾先出現？

## 比較的是哪些股票與時點

資料為 2019-01-02～2026-08-14，51,731 次頭頭高、底底高第四版突破，來自 1,864 檔股票。沿用波峰、波谷逐步墊高後突破的事件，再檢查不同價位條件及後來跌破支撐的情況。比較對象是沒有相應型態的新高量能組，以及收盤創近 250 日新高組。新高量能沿用第四版的前 20 筆收盤新高與均量 1.5 倍規則。例：突破日收 100 元，追蹤約半年／一年（126／252 個共用交易觀察）有沒有曾達 200 元；未曾達 200 元、到期又低於 100 元，才列為未翻倍收低。

## 半年與一年翻倍比例，都低於兩個新高對照

| 組別           | 半年翻倍率／已知數 | 一年翻倍率／已知數 |
| -------------- | -----------------: | -----------------: |
| 全部型態突破   |      7.81%／45,956 |     15.97%／40,720 |
| 新高量能對照   |      8.25%／96,624 |     16.90%／85,118 |
| 250 日新高對照 |     10.60%／40,140 |     18.00%／36,224 |

一年內未翻倍的事件中，72.32% 曾跌破原型態最後確認低點（Z2）；最終翻倍的事件中，25.13% 也在首次翻倍之前跌破過。例：起點 100 元、原低點 90 元，先有一天收盤 89 元、後來收盤才升到 200 元，便屬後一組。兩個比例分母不同，觀察終點也不同：未翻倍者看完整一年，翻倍者只看到第一次達標。

## 這份結果和後續研究的關係

原 mission 開頭仍是準備狀態；完整報告已記固定計算完成。網頁追加文字指出另一半一年期可比較的 7 個候選均低於同條件 250 日新高；這項文字證據可讀，原 HTML 保留。[前一份第四版研究](../20261010-hhhl-v4-probability/report.md)允許先達標的事件保留結果，本頁則要求完整追蹤日曆，兩份比例的分母不同。

## 這次回答到哪裡

加上強勢條件後，型態組比例升高，相同條件的新高組也升高。另一半資料的七個可比一年期候選，仍低於同條件的 250 日新高組；型態的額外優勢尚未建立。
