理解結果的邊界

固定選股與 v1 比較

選股範圍：fixed-v1-known-return-leaders。只補全 v1 報酬可計候選中的原領先股，沒有重排全市場；未知候選仍可能更好。

表內 v1 是原報告的四捨五入值；v2 使用本次資料版本。兩者不是同一批輸入的精確相等測試。原來未知的值仍以「未知」保留，不補成零。

開啟未改寫的 v1 閱讀版

股利、認股權與成本假設

現金股利仍為估值，假設除息日收盤立刻再投入分數單位；不代表實際付款日或歷史零股可成交性。認股權價值實現屬模型情境，並非實際行使或外部資金注入。

雙邊各收佣金 0.1425%；各邊不利滑價 0.1%；股票賣方稅 0.3%；ETF 賣方稅 0.1%。再投入另收佣金；未充分處理個人稅負、最小佣金及整股資金限制。未扣成本／扣成本後分別對應原資料 gross／net。

沿用前值標記與資料缺口

沿用前值標記僅支援終值建模；停牌或無報價資訊日不代表能以該價成交。無報價資訊（N）表示缺少開高低收，不據此推論成交筆數一定為零。只要每日路徑不完整，完整每日最大回撤便維持未知，參考回撤另列。
