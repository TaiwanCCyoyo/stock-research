# 2B 與均線匯聚模板：版本不同，尚不能合併判讀績效

閱讀版更新：2026-11-02。歷史待整理；原檔保留，沒有重跑。

## 原始問題

2B 加均線匯聚模板能否完成指定台股池的回測與報告流程？這是模板 smoke test，不是全市場策略驗收。

## 實際比較

任務列出 22 檔、起始日 2022-01-01；nightly report 與 walkthrough 的執行段卻寫 2024-01-01 起，結束日只寫「最新本地資料」。walkthrough 記載初始資金 1,000,000 元。基準是同池等額買進持有，另有整數股版本；不是單純拿 0050 當所有版本的共同基準。

## 答案

nightly report 保存的策略報酬為 −8.624700%，同池買進持有為 88.334074%；另一份標示 2026-06-21 重跑的診斷卻報 +2.00%。兩者期間與版本不同，目前不能選一個當本任務的唯一結論。

前者的 trade count 為 302，不能直接解讀為完整買賣部位數；策略包含分批賣出。後者列出 451 筆平倉統計，也不應拼接到前者的報酬表。

## 未回答與限制

保存的報告沒有建立一致的執行期間與版本對照；任務預檢的資料最末日也不能替代實際回測結束日。因此不提供合併資料期間，也不據此判定 2B 型態有效或無效。

## 可支持的決策

可用來辨認早期模板的流程與設定問題，不能作為現行策略選擇。診斷中事後剔除虧損股票的建議不是已驗證改善；本閱讀版不把它變成後續執行指示。

## 後續研究與修正

後來的 2B 進場拆解發現，相關原型把動能與 2B 用「或」連接，不能把混合策略績效當成純 2B 效果；它也指出分批賣出次數與部位數不同、整張限制可能造成低投入。該研究改變了股票池、期間與部位大小，不能回填本 smoke 的數字。原診斷與後來文章對零成交檔數的描述亦不一致，本版不採用該檔數作結論。
