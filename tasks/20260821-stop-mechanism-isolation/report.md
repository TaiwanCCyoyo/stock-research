# 停損機制隔離實驗 — 箱底棘輪贏的是報酬，不是回撤

**回測期間** 訓練 2019-01-02 ~ 2023-12-31 / 驗證 2024-01-01 ~ 2026-08-14
**設計** 同一個唐奇安進場，只換出場機制 · 2 臂 × 5 族群 × 4 跑法 = 40 個 cell
**前作** `20260820-kline-archetype-extension`（Darvas 表現最好，但機制混淆）

---

## 一、先講結論

前一份研究發現 Darvas 箱型的交易形狀與回撤都是六個原型裡最好的，並推測「結構型停損可能勝過 ATR 停損」。**但那個推測無法從該研究得出**，因為 Darvas 與其他策略同時差在進場與出場兩處。這次把進場固定成 S1 唐奇安（程式碼層級證明相同），只換出場。

結果乾淨地一分為二：

**1. 棘輪確實改善每次進場的損益，而且非常一致 —— 規則 2 通過。**
驗證期 **5/5 個族群全部勝出**，合併後 5.76% 對 3.73%。訓練期同向（4/5 勝、4.95% 對 3.60%），沒有翻號。以預先登記的標準（≥4/5 且合併值較高）判定為**成立**。

**2. 但棘輪沒有改善風險 —— 規則 3 未通過，而且方向相反。**
報酬/回撤在驗證期只勝 3/5、訓練期只勝 2/5，都低於 4/5 門檻。更值得注意的是**最大回撤本身經常變差**：訓練期半導體 −16.5% → −21.1%、電腦週邊 −14.1% → −19.6%。

**這推翻了我自己在前一份報告裡寫下的推測。** 那份報告說 Darvas 的 −6.9% ~ −15.2% 低回撤來自結構型棘輪。現在把棘輪單獨拿出來測，它並不壓低回撤，反而常常拉高。**Darvas 的低回撤來自它的進場（極度選擇性、驗證期只出手 12–29 次），不是它的出場。**

**3. 機制是什麼，持有期間講得最清楚。**
棘輪讓每筆持倉拉長 **20~47%**（半導體 33.7 → 49.6 個日曆天 = +47%、金融保險 37.5 → 53.2 = +42%），進場次數因此變少（217 → 182），而賺賠比明顯提升（半導體 5.19 → 7.03、電子零組件 4.53 → 5.27）。

**棘輪的作用是「在漲勢中讓開」，不是「把風險切緊」。** 停損只在箱型確認時才上移，而每次創新高都會重啟箱型形成 —— 所以急漲段裡停損長時間不動，賺的部位抱得更久。代價正是回撤：停損離價格更遠。

**一句話**：這是一個可以掛到任何突破進場上的**報酬增強元件**，不是風險控制元件。要用它就要接受更大的回撤換更大的賺賠比。

## 二、單一變數是用程式證明的，不是用眼睛看的

整個實驗的價值都押在「進場真的一模一樣」。所以 `verify_isolation.py` 在掃描前先跑，比對兩個檔案的 AST：

| 檢查                                                 | 結果 |
| ---------------------------------------------------- | ---- |
| `should_enter` 可執行碼相同（排除 docstring）        | ✅   |
| `equal_notional_quantity` 可執行碼相同               | ✅   |
| 兩臂 `warmup()` 相等（都是 61）                      | ✅   |
| `entry_lookback` / `trend_ma` / `exit_lookback` 相等 | ✅   |
| 出場機制確實不同                                     | ✅   |

**8/8 通過。** docstring 刻意排除 —— 說明文字可以不同，程式碼不行。加上 `analyze_isolation.py` 的配對檢查（20 對 cell 兩臂都載入相同標的、相同資料缺口），差異只可能來自出場。

| 臂   | 進場                      | 出場 / 停損                                                    |
| ---- | ------------------------- | -------------------------------------------------------------- |
| 對照 | 20 日收盤新高 + 站上 MA60 | 跌破 10 日低點，或進場 − 2×ATR（固定不動）                     |
| 實驗 | **完全相同**              | 停損掛在最近一個已確認 Darvas 箱型的箱底，隨新箱上移，只升不降 |

## 三、主要結果

### 3.1 驗證期 每次進場平均損益 %（主要指標）

| 族群       | ATR 停損 | 箱底棘輪  | 差異  | 棘輪較優 |
| ---------- | -------- | --------- | ----- | -------- |
| 半導體     | 8.56     | **17.58** | +9.02 | ✅       |
| 電腦週邊   | 1.05     | 1.19      | +0.14 | ✅       |
| 電子零組件 | 8.54     | 9.33      | +0.79 | ✅       |
| 金融保險   | 1.44     | 2.25      | +0.81 | ✅       |
| 航運       | −0.28    | −0.00     | +0.28 | ✅       |

**5/5 勝出。** 訓練期 4/5 勝出（唯一的例外金融保險是 0.75 對 0.74，實質打平），方向一致。

### 3.2 合併五族群

| 臂           | 訓練期 %/進場 | 驗證期 %/進場 | 驗證期平倉數 |
| ------------ | ------------- | ------------- | ------------ |
| ATR 停損     | 3.60          | 3.73          | 1,038        |
| **箱底棘輪** | **4.95**      | **5.76**      | 920          |

樣本充足（兩臂各 900+ 筆平倉），這正是選唐奇安當載體的理由 —— Darvas 自己的進場在驗證期單族群只有 12–29 筆，測不出結論。

### 3.3 風險：規則 3 未通過

驗證期 報酬/回撤：

| 族群       | ATR   | 棘輪  | ATR 最大回撤% | 棘輪 最大回撤% | 棘輪較優 |
| ---------- | ----- | ----- | ------------- | -------------- | -------- |
| 半導體     | 4.31  | 6.22  | −32.8         | −29.7          | ✅       |
| 電腦週邊   | 1.19  | 1.12  | −23.2         | −21.4          | ❌       |
| 電子零組件 | 8.56  | 5.69  | −20.3         | −30.9          | ❌       |
| 金融保險   | 0.88  | 1.43  | −23.9         | −24.4          | ✅       |
| 航運       | −0.33 | −0.24 | −24.9         | −23.9          | ✅       |

**3/5，未達 4/5 門檻。** 訓練期更差（2/5），且最大回撤本身在 5 個族群裡有 3 個變大。**風險面沒有證據支持棘輪。**

最能說明問題的是**電子零組件**：每次進場損益是改善的（8.54 → 9.33），但最大回撤從 −20.3% 惡化到 −30.9%（放大 52%），是整個網格裡最差的風險結果。**在同一個族群裡報酬變好、風險大幅變壞** —— 這一組數字比 3/5 的計票更直接地說明棘輪換的是什麼。

### 3.4 機制：持有期間與交易形狀

| 族群       | ATR 持有天數 | 棘輪 持有天數 | 變化 | ATR 賺賠比 | 棘輪 賺賠比 |
| ---------- | ------------ | ------------- | ---- | ---------- | ----------- |
| 半導體     | 33.7         | 49.6          | +47% | 5.19       | **7.03**    |
| 電腦週邊   | 29.0         | 36.8          | +27% | 2.39       | 2.34        |
| 電子零組件 | 36.5         | 43.9          | +20% | 4.53       | **5.27**    |
| 金融保險   | 37.5         | 53.2          | +42% | 2.40       | 2.22        |
| 航運       | 24.9         | 32.0          | +29% | 2.32       | 2.29        |

（日曆天，不是交易日 —— summary 記的是成交日期而非 bar 序號。兩臂跨相同日期、相同標的，所以彼此比較不受影響，只是絕對數字比實際 bar 數大約 1.4 倍。）

抱得更久 + 賺賠比提升 + 回撤變大，是同一件事的三個面向。

## 四、效度檢查：有多少進場其實沒用到箱型

唐奇安突破不是箱型突破，所以進場可能發生在箱型還沒確認的時候，此時停損落到 fallback（前 10 根 K 的最低點）。若這個比例過高，實驗組測的就是 fallback 而不是棘輪。

`fallback_exposure.py` 用 DataLoader 重播同一批 K 棒，在實驗組每一個真實進場日檢查當時是否已有確認箱型：

| 窗口     | 進場數    | 有已確認箱型 | 箱型覆蓋率 |
| -------- | --------- | ------------ | ---------- |
| 訓練期   | 1,918     | 1,289        | 67.2%      |
| 驗證期   | 973       | 680          | 69.9%      |
| **合計** | **2,891** | **1,969**    | **68.1%**  |

**68.1% 高於我事前設的 50% 門檻，實驗有效。** 但仍有約三分之一的進場走 fallback，所以嚴格說，測到的是「棘輪為主、通道停損為輔」的混血，真正純棘輪的效果應該比這裡量到的更強。這偏保守，不影響結論方向。

## 五、一個必須講清楚的資料問題

**本研究的絕對數字與 20260816 那份研究不可比較，而我原本設計的重現檢查就是因此失敗的。**

`corporate_actions.sqlite` 裡 **2018–2025 年的每一筆事件，`fetched_at` 都是 2026-08-17** —— 也就是 20260816 研究跑完的隔天。那份研究幾乎沒有除權息還原，之後所有回測都有完整還原。用同一支 S1 程式在兩個時點跑，訓練期 `total_pnl` 差 **+10.8% ~ +28.1%**，以配息最重的金融保險差最多（+28.1%）—— 方向與排序都正是「加入股息現金」該有的樣子，這也是判定原因的依據。

兩邊在各自的資料版本下都是對的，只是不能並排比較。專案記憶本來就記著這件事（「2026-08-17 backfill，pre/post backtests not comparable」）。

**連帶影響**：`20260820` 那份報告第七節的「六個原型併表」把 S1–S3（backfill 前）與 S4–S6（backfill 後）放在同一張表，這是一個真實缺陷。修正方式是用 `refresh_prior_arms.py` 把 S1–S3 在當前資料版本重跑，該報告與其發布頁面已據此更新。

## 六、限制

1. **fallback 稀釋 32%。** 見第四節。方向偏保守。
2. **`high_lookback` 被改成 20（Darvas 原文是 52 週）。** 必要之舉：箱型必須圍繞唐奇安進場所依據的那些高點形成，否則幾乎每筆都走 fallback，測到的就只是 fallback。但這代表本研究測的是「短週期箱型棘輪」，不是 Darvas 原始的長週期版本。
3. **只在一個進場上測過。** 結論是「棘輪掛在唐奇安突破上會這樣」。要主張它是通用元件，還需要掛到 S2、S3 上重測。
4. **回撤結論的樣本較弱。** 風險比較用 `shared` 模式，每個族群只有一條權益曲線，5 個族群就是 5 個觀察值 —— 遠不如損益比較的 900+ 筆交易穩健。「棘輪不改善回撤」的信心低於「棘輪改善損益」。
5. **沿用既有限制**：倖存者偏誤、收盤價成交、除手續費與 0.3% 證交稅外無滑價模型、兩個窗口都是多頭。

## 七、下一步

1. **把棘輪掛到 S2 K線反轉與 S3 動能突破上。** 這是把「報酬增強元件」從一個觀察升級成通用機制的唯一方法，而且兩支的樣本都夠（S2 驗證期 428 筆、S3 811 筆）。20 個 cell，成本很低。
2. **回頭修正對 Darvas 低回撤的解釋。** 既然棘輪不壓回撤，Darvas 的 −6.9% ~ −15.2% 就是它進場極度選擇性的結果。這反而讓「擴大 Darvas 樣本」更值得做 —— 要複製的是它的挑股嚴格度。
3. **測「棘輪 + 較緊的災難停損」。** 棘輪拉高賺賠比但也拉大回撤，補一道固定的最大損失上限（例如 −10%）也許能兩者兼得。這是本研究最直接的延伸。
4. **前作留下的「緊出場在循環股是否通用」仍未測。**
