台股 · 描述性研究 · 2010–2026 已看過的期間

只看強勢條件，不看型態：翻倍與大漲的機率

不看任何型態，只要股價已經很強（收盤高於年線六成、是一年低點的 2.5 倍），半年內翻倍的比例是 14.5%，全市場任何一天是 3.9%；再加上當天漲停，升到 18.8%。 但這些股票期末賠錢的比例也比較高：強勢條件讓「翻倍」和「賠錢」同時變多，是高波動的股票，不是穩賺的訊號。

怎麼讀這頁： 「翻倍」只代表期限內收盤曾經達到兩倍，不等於實際買賣能拿到的報酬（沒有進出時點、成本與持有決策）。 所有數字都是 2010–2026 已看過的歷史描述，條件本身就是從這段資料挑出來的，不能當作新證據。 型態到底額外貢獻多少（型態分解）這次沒有評估：需要 PR17 把每天各型態的原始狀態發布成可重用資料。
