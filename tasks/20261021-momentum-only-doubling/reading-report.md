# 已大漲的強勢股，較常再翻倍，也較常沒翻倍就收低

閱讀整理：2026-11-04。

**只看已大漲的強勢股，從符合條件當日收盤起往後半年內曾翻倍的比例為 14.5%；不另要求強勢條件的合格股票日基準為 3.9%。但沒翻倍又收低的比例也較高，型態在強勢條件之外多提供多少，這次仍未回答。**

條件從同一段已看過的歷史選出；同一股票的連續日期會重複計入。原研究缺少型態每日狀態，因此沒有計算型態的額外貢獻。

研究問題：完全不看型態的強勢條件能解釋多少大漲？型態另有多少貢獻？

## 強勢是已經漲很多，再看後來有沒有翻倍

資料為 2010-01-04～2026-10-12，沿用 1,942 檔普通股參考名單。每日先檢查資料與資格，再分三組：

| 組別                        | 當天要符合的條件                                                     |
| --------------------------- | -------------------------------------------------------------------- |
| 全部合格觀察                | 不另要求股價強勢，作為比較基準                                       |
| 強勢組（CORE）              | 收盤至少是近 240 日均價的 1.6 倍，且至少是近 250 日最低收盤的 2.5 倍 |
| 強勢且當日大漲組（LEAD_B1） | 同時符合強勢組，且當天原價漲幅至少 9.5%                              |

均價、低點與後續翻倍追蹤，均使用原研究指定的還原價；只有當日漲幅至少 9.5% 的代理條件使用原始收盤價。

假設當天還原收盤價 100 元：近一年均價必須不高於 62.5 元、近一年最低收盤不高於 40 元，才符合強勢組。這些是說明門檻的假設數字；接下來問的是，從這個 100 元起點還會不會漲到 200 元。

時間順序：**先看過去約一年 → 當天符合條件、以收盤作起點 → 追蹤之後約半年（126 個交易日）或一年（252 個交易日）。**

期限內收盤曾達 200 元，算翻倍；從未達 200 元、到期又低於 100 元，才算未翻倍收低。曾達 200 元後再跌回 100 元以下，仍歸翻倍。

## 半年翻倍較多，未翻倍收低也較多

| 每日組別         | 半年內曾翻倍 | 半年未翻倍且到期收低 |
| ---------------- | -----------: | -------------------: |
| 全部合格觀察     |         3.9% |                47.3% |
| 強勢組           |        14.5% |                53.1% |
| 強勢且當日大漲組 |        18.8% |                52.5% |

每一列兩個比例的分母相同：該組有完整半年觀察期、結果可判定的股票日期。兩個比例不加總為 100%，因為還有沒有翻倍、但到期持平或上漲的觀察。半年收低比例的差距，在兩種處理樣本重複的不確定性估計中並非都能清楚區分。

## 拉長到一年，收低比例仍較高

| 每日組別         | 一年內曾翻倍 | 一年未翻倍且到期收低 |
| ---------------- | -----------: | -------------------: |
| 全部合格觀察     |         9.8% |                45.1% |
| 強勢組           |        18.2% |                60.1% |
| 強勢且當日大漲組 |        21.7% |                60.1% |

這張表改用有完整一年觀察期、結果可判定的股票日期，因此與半年表的筆數不同。一年期的翻倍和未翻倍收低差距，原報告的兩種不確定性估計方向一致。表內比例不是股票檔數比例，也不是另行間隔取樣的事件數；原表的冷卻樣本數不能拿來當上述百分比的分母。

## 原題的另一半：型態有沒有多提供資訊？

這份研究承接[型態掃描研究](../20261013-pattern-scan/report.md)的股票範圍與比較基準，拿掉型態，只留下強勢條件。原研究在 2026-10-22 完成這項歷史比較，但缺少當時所需的型態每日原始狀態，額外貢獻仍記為未評估。

型態研究已有正式階段報告；其頁面仍標示研究尚未全部完成。本頁不再使用「另一個 session 正在修訂」作狀態，也沒有把後來的報告修訂當成這份研究已完成型態分解。兩份報告的事件篩選與分母不同，現有比例不能直接相減得到型態貢獻。

## 當日大漲組的年代範圍較短

9.5% 是原研究用來近似漲停的門檻。2015 年 6 月以前的一般漲跌幅限制為 7%，因此這組主要涵蓋 2015-06 以後，與全部期間基準的年代組成不同。原報告另列 2019 年後：強勢且當日大漲組半年翻倍 20.0%、強勢組 17.5%、基準 5.7%。這是同年代的補充比較，沒有取代上面保存的全期間結果。

這次結果呈現機會與收低同時增加的取捨；尚未計算實際帳戶的持有、成交與成本。前瞻紀錄另行累積，歷史比較完成不表示前瞻追蹤也完成。
