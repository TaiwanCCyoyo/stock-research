# 只看強勢條件：翻倍與收低都增加，型態增量未回答

閱讀版更新：2026-11-02。這是保存證據的閱讀整理；可讀不等於策略通過或擁有者驗收。

## 問題與答案

完全不看型態的強勢條件能解釋多少大漲？型態另有多少貢獻？

**純強勢條件的歷史翻倍率較高，但未翻倍收低也較多；型態額外貢獻仍未評估，不能宣稱已回答原題全部。**

## 實際比較

沿用 1,942 檔參考普通股、S6 逐日資格與研究價。CORE 為收盤至少 1.6 倍 MA240 且至少一年低點 2.5 倍；LEAD_B1 再加原價單日 ≥9.5% 代理。每日條件集只跟每日基準比，冷卻事件另列。

## 結果與分母

| 每日組         | H126 翻倍／未翻倍收低 | H252 翻倍／未翻倍收低 |
| -------------- | --------------------: | --------------------: |
| CORE           |          14.5%／53.1% |          18.2%／60.1% |
| LEAD_B1        |          18.8%／52.5% |          21.7%／60.1% |
| 合格股票日基準 |           3.9%／47.3% |           9.8%／45.1% |

分母為同期限、完整日曆且結局已知的合格股票日期；不是冷卻樣本 K（例如 CORE H126 的 5,983）也不是股票檔數。翻倍是曾達目標；先翻倍後收低仍算 hit。

## 能支持的決定與未回答部分

支持討論純強勢的機會與下行取捨；沒有回答型態增量、實際帳戶獲利或前瞻有效性。9.5% 代理使 LEAD_B1 不涵蓋 2015-06 前常態漲停，年代組成要並讀；前瞻累積不能由歷史報告完成推定已完成。

**主要限制：條件從同一段已看過歷史選出；每日比例不是交易勝率，型態原始狀態缺件使分解與 share 均不可判定。**
