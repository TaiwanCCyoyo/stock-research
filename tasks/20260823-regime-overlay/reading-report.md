# 市場轉弱後換現金或 0050，沒有找到穩定合格的設定

部分市場轉弱設定減少了帳戶跌幅，但沒有一組相鄰三個門檻都同時保住報酬、回撤與換手要求。較好看的單點結果，對改放現金還是持有 0050 十分敏感。

比較期間：訓練 2019-01-02 至 2023-12-31；驗證 2024-01-01 至 2026-08-14。

市場轉弱訊號長期統計與策略回測的期間不同；原換手規則未明訂兩期都要通過，實作只檢查驗證期。

## 同一個市場訊號，接上兩種不同反應

研究原問：動能十檔策略遇到市場轉弱時，改放現金、改持 0050 或增加均線條件，能否減少跌幅又保住報酬？[降低周轉研究](../20260823-turnover-mechanism/report.md) 提供「近期漲幅前十名、至少持有二十個交易日」的基準；本次另加市場判斷與配置反應，共 29 個變體。

其中一個訊號看上市股票每日上漲家數比例，再取二十日平均，低於一半就標記市場轉弱（d3_ad50）。定義示例：若平均只有 100 檔中的 45 檔收漲，就低於 50% 門檻。被替代的股票市值改放現金或 0050；這個例子說明訊號門檻，並非實際樣本。

## 持有哪種資產，明顯改變這個訊號下的結果

| 同一驗證期：2024-01-01 至 2026-08-14 | 帳戶淨報酬 |
| ------------------------------------ | ---------: |
| 原動能十檔基準                       |     +81.8% |
| 上述訊號觸發時改持 0050              |    +159.4% |
| 上述訊號觸發時改放現金               |      +2.6% |

原基準的最大回撤為 −53.3%，即帳戶從先前高點到低點的最大跌幅。這張表使用引擎帳戶淨值；它與前篇「部位報酬加總」有不同計算方式。

另在 2013-08-01 至 2026-08-20 的市場轉弱訊號長期統計，這個訊號標記了 91.8% 的日期。該比例涵蓋較長歷史，並不是本表驗證期的單獨標記率。結果顯示資產選擇很重要，但現有對照沒有把偵測器本身的增量貢獻單獨估出來。

## 一個門檻好看，鄰近門檻未必一起成立

策略訓練期為 2019-01-02 至 2023-12-31；偵測器較長的歷史只用來描述訊號，沒有增加策略績效期間。原設計要求連續三個參數值都符合條件，以免結論只落在一個孤立設定；本次沒有形成這樣的區間。

報告另有靜態混合 0050 的事後試算，但未計再平衡成本。它與市場訊號觸發後轉換資產，也是不同配置問題。

## 後續改清楚了規則，也改問不同的結果

本篇已修正「驗證期全是多頭」與「2022 必然最差」的前提，並將按進場年累積的部位損益與帳戶年度報酬分開。[排序視窗任務](../20260824-ranking-horizon/mission.md) 後來明定換手上限須兩期都過；[大幅上漲研究任務](../20260826-tail-selection/mission.md) 再區分「篩出大漲股」與「帳戶勝過指數」。這些後續問題沒有被本次 29 個變體一併回答。
