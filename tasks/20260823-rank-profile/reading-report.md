# 前十名與後面名次的差距，在驗證期還量不清楚

驗證期沒有量出前十名與後面名次帶的明確報酬差距；但只有 30 個不重疊取樣日，現有精度不足以確認它們相同。

比較期間沿用排序與隨機選股研究：訓練 2019-01-02 至 2023-12-31；驗證 2024-01-01 至 2026-08-14。

比較的是每個日期當下不同股票的排名組別，沒有追蹤某筆持股排名下降後繼續持有的帳戶結果。

## 同一天分組，再看接下來二十個交易日

研究原問：排名前十的股票，接下來約一個月是否比第十一到六十名更好？本篇是事後診斷，沒有獨立 mission。

它沿用 [排序與隨機選股研究](../20260823-selection-vs-random/report.md) 的五種分數與合格股票池。訓練期 2019-01-02 至 2023-12-31，驗證期 2024-01-01 至 2026-08-14；同日各組都看未來 20 個交易日淨報酬。

比較順序是：取樣日分成前十名、第 11–30 名、第 31–60 名等組 → 各組追蹤未來 20 個交易日 → 同日報酬相減。每組先扣全池均值，再與前十名配對。假設兩組未來報酬分別 10% 與 8%，差就是 2 個百分點；這是計算示例。

## 較少的取樣日，留下較寬的不確定範圍

| 動能排名：第 11–30 名相對前十名 | 取樣日數 |     平均報酬差 |
| ------------------------------- | -------: | -------------: |
| 訓練期                          |       53 | −2.87 個百分點 |
| 驗證期                          |       30 | +1.74 個百分點 |

這裡用間隔二十個交易日的取樣，減少相鄰結果重複涵蓋同一天。訓練期的負差在驗證期沒有重現；驗證期五種分數、四個名次帶的比較，都未達原表「差距相對誤差至少兩倍」的界線（|t| ≥ 2）。

驗證期動能前五名的估計標準誤達 2.45 個百分點。標準誤描述這個平均數估計有多不穩定；樣本未呈現明確差距，仍可能同時容納相當不同的真實差異。

## 後續真的改了持有規則，結果並不相同

[周轉機制研究](../20260823-turnover-mechanism/report.md) 才讓已買進股票在排名落後時繼續留在帳戶。放寬排名區間在訓練期改善、驗證期卻反轉，說明「今天不同名次股票的平均」與「昨天買進的股票繼續持有」是不同路徑。

本診斷也撤回了僅由前五名較低的表現百分位，就認定持股集中一定增加風險的說法；前五名的估計本身較不精確。
