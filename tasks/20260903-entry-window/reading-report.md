# 64 檔事後大漲股的上榜機會較長，尚未回答晚下單的帳戶結果

閱讀版更新：2026-11-04。數字沿用下列保存來源。

**研究問題：** 離開幾天沒下單，是否會完全錯過後來大漲的股票？

2019-01-02 至 2023-12-31，事後漲幅達 150% 的 64 檔股票，累計在前 30 名的天數中位數為 67 個交易日，並非連續在榜。從首次進入近期漲幅前十名起晚 20 個交易日買進，不要求當天仍上榜，至事後高點的可得漲幅中位數仍保留 85%；這是價格窗口，沒有模擬帳戶買賣。

**主要限制：** 只看2019-01-02至2023-12-31的訓練期與事後大漲股票；沒有測到事前辨識、資金競爭、錯過賣出或實際成交。

[延長持有研究](../20260826-runner-retention/report.md)提供大漲股票的母體定義；本篇量它們的上榜窗口，後續[排名延遲研究](../20260904-execution-delay/report.md)再把延遲放進帳戶。

## 實際比較與數字

排名依最近 20 與 60 個交易日的漲幅合成。「事後漲 150%」的定義是首次進前十名後最多 250 個交易日內，價格曾達起點的 2.5 倍；假設起點 100 元，就是曾到 250 元。先依此挑出 64 檔，再量它們在前 30 名出現多久，因此不是從全部訊號估計成功率。

| 觀察順序                | 這一步做什麼                                           |
| ----------------------- | ------------------------------------------------------ |
| 首次進前十名            | 固定起點價格，不因換成前 30 名比較而改變               |
| 起點後最多 250 個交易日 | 判定是否曾漲 150%，到研究期末仍未滿 250 日者受右端截斷 |
| 起點到事後高點          | 計算在榜天數，以及晚買後剩餘漲幅占原可得漲幅的比例     |

以首次進入分數前10名為起點，往後最多250個交易日；漲幅達150%的母體有64檔。分母始終是這64檔，不因改看前30名而換母體。

| 量測                                  | 保存結果    | 正確讀法                                     |
| ------------------------------------- | ----------- | -------------------------------------------- |
| 前30名機會天數中位數                  | 67個交易日  | 在榜日可不連續                               |
| 首次至最後一次在榜的窗口中位數        | 168個交易日 | 不是168天每天都能進場                        |
| 整個前30名窗口短於或等於20日          | 0%          | 這64檔的回顧描述，不是漏接機率保證           |
| 直接延後3／20個交易日的漲幅保留中位數 | 98%／85%    | 相對首次上榜至事後高點的可得漲幅，非帳戶報酬 |
| 跳過前20次前30名訊號後的保留中位數    | 63%         | 與離開20個交易日是不同情境                   |

按交易日延後的版本回來就買，不要求當天仍在榜上；這不同於回來後依最新訊號重新決策。右端資料會截斷晚發生的行情。

## 這次還沒有回答什麼

沒有納入非飆股，因此不能用64檔推估一個未知訊號成功的機率。2344的動機案例落在另一段期間，未列為本卡訓練期證據。原標題所暗示的「出去玩也不會錯過」超出這個回顧母體能保證的範圍。

後續延遲執行研究把排名整體延後，三日設定的飆股份額只保留基準80.7%，未通過。它補上帳戶問題，但仍不是完整的缺席後重新決策模擬。討論下一步應先固定缺席、回來決策及未成交的語意，不把價格窗口當作操作韌性。
