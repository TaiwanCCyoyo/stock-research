# 加碼後回到損益零點就退：總體試錯成本反而增加

閱讀版更新：2026-11-02。這是保存證據的閱讀整理；可讀不等於策略通過或擁有者驗收。

## 問題與答案

實際加碼後，經濟估值損益回到零或以下即退出，能否改善試錯？

**零錨點退出使非命中淨現金惡化、委託增加，這個固定機制未通過原篩選。**

## 實際比較

2019–2023，初始 200 萬、最多五檔，首次 10 萬／一次加碼 30 萬；比較原 100/300 與無加碼 fixed100。只增加實際加碼後的固定退出意圖，後續現金與重新進場均隨模擬改變。

## 結果與分母

| 指標                   |   原 100/300 |   零錨點退出 |
| ---------------------- | -----------: | -----------: |
| 淨利（元）             | 3,082,857.21 | 2,206,927.55 |
| 完成非命中淨現金（元） |  +360,873.54 |  -170,469.40 |
| 委託／操作晚數         |     715／550 |     867／631 |

候選淨利仍高於 fixed100（後者淨利為 686,676.93 元），但非命中正現金減少超過負現金改善。71.59% 淨利保留只是相對另一策略，並非延遲韌性 70% 測試。

## 後續結果與修正

後續加碼階段診斷顯示實際加碼組非命中淨現金為正、未加碼組為負；該事後分組不能反向證明加碼因果效果，也沒有推翻此退出失敗。

## 能支持的決定與未回答部分

可停止此精確退出設定的晉級，將初始試單品質列為另外問題。已知局部侵蝕減少不代表整體變好；未結束部位仍阻止全域二十次損失認證。

**主要限制：觸發零點不保證實際成交損益為零；本批未做缺席、延遲、最佳嘗試移除或獨立確認。**
