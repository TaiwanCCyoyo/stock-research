# 每週才檢查退出，省下操作卻增加試錯損失

閱讀整理：2026-11-04。

**每週才檢查排名退出，少操作 89 晚；但非命中持股由合計賺 39.64 萬元轉為虧 41.54 萬元。**

兩個帳戶都還有未結束持股，最差連續二十次序列仍未知；這種分組現金損失與整個帳戶從高點回落的幅度不同。

研究問題：把排名退出改成每週檢查，能否減少操作並保留收益？

## 比較的是哪些股票與時點

2019–2023 年，相同 200 萬元、最多五檔、首次一張及既定加碼規則。原版本每日檢查排名是否觸發退出，新版本只在每週第一次檢查；其他進場與退出條件不變。兩組使用同一期末安排，保留兩個不新增建議的交易日。

表內「非命中」沿用原報告分類，指已結束、但沒有被列為捕捉到大漲的持股嘗試，包括小賺與虧損；其淨現金是這一組收支的合計。委託次數包含沒有成交的單，操作晚數是一晚有工作就計一次。
