# 每週才檢查排名退出：少操作，但試錯侵蝕加重

閱讀版更新：2026-11-02。這是保存證據的閱讀整理；可讀不等於策略通過或擁有者驗收。

## 問題與答案

把排名退出改成每週檢查，能否減少操作並保留收益？

**每週退出減少委託，卻使非命中淨現金轉負且已知損失窗口惡化，未通過固定篩選。**

## 實際比較

2019–2023，200 萬／最多五檔，採兩安靜日配對每日帳戶；初始一張及加碼規則不變，只固定每週首次檢查排名退出。

## 結果與分母

| 指標                     |         每日 |         每週 |
| ------------------------ | -----------: | -----------: |
| 淨利（元）               | 2,934,085.15 | 2,589,764.55 |
| 完成非命中淨現金（元）   |  +396,434.48 |  -415,417.46 |
| 委託／操作晚數           |     714／549 |     620／460 |
| 已知二十次從零侵蝕（元） |   425,961.59 |   494,396.59 |

淨利保留 88.26%，但固定條件還要求非命中淨額與已知窗口不得惡化，不能只挑保留率說通過。

## 後續結果與修正

採完整 v2，v1 部分執行保留。後續波段參與診斷顯示高點持有從 75 增至 77 段，沒有支持救回此設定。

## 能支持的決定與未回答部分

支持停止此精確版本的晉級；可另討論進場與試單風險，不能自動改週期、排名或停損。兩帳戶全域窗口仍未知，獨立確認與 owner 最終損失預算尚未完成。

**主要限制：只否定這個每週排名退出設定的晉級；非命中現金窗口不是帳戶回撤，也未證明所有週策略無效。**
