# 反向調整後才出現正向結果，兩檔探索仍缺完整驗證脈絡

兩檔股票的第一次調整沒有通過；改往相反方向探索後，八次嘗試中有四次在保存紀錄中被標為通過條件。這份結果留下參數線索，但原先「停損更緊、匯聚條件更寬」的假設並未完整成立。

任務指定期間：2022-01-01 至 2024-06-30；訓練與驗證兩個子期間的精確分界未保存。

同一驗證資料被查看六次；保存報告沒有訓練與驗證子期間的日期邊界、交易筆數及指標貨幣單位。

## 第一個方向失敗，之後改試相反方向

研究原問：縮緊停損、放寬均線匯聚條件，能否改善 2330 與 2454 的平均每筆損益？縮緊停損是容許較小跌幅，均線匯聚則看不同長度的平均價格是否接近；本次同時探索這兩個參數。

任務指定兩檔股票、2022-01-01 至 2024-06-30。報告將資料分為訓練與驗證兩部分，但沒有留下分界日。

| 探索過程                             | 保存結果                                  |
| ------------------------------------ | ----------------------------------------- |
| 第一次：依原假設方向調整             | 訓練期平均每筆損益指標 −6410.0870，未通過 |
| 第二次起：反向放寬停損、收緊匯聚條件 | 開始出現通過組合                          |
| 第八次：停損參數 7.5、匯聚參數 1.5   | 訓練指標 11979.8333，驗證指標 19512.4000  |

這些是原表的 expectancy 讀數，即平均每筆損益指標；因來源未列分母與貨幣單位，表中保留指標值。八次探索共有四次兩部分都過、兩次只過訓練、兩次訓練就未過。多個通過組的驗證讀數相同。

## 參數結果與進場來源仍是兩個問題

反覆查看同一驗證部分，提供的是同一次探索中的比較，而非六份新資料。保存的紀錄也沒有單獨拆開停損、匯聚與進場型態的影響。

後來的 [2B 進場拆解](../20260821-2b-entry-decomposition/report.md) 用更大的產業股票池，區分價格轉強與跌破低點後收回的 2B 訊號，另比較減碼。它提供方法上的拆解，沒有重現本次兩檔股票的相同設定。
