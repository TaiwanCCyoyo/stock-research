# 強勢股再加突破或拉回條件，結果沒有一致變好

閱讀整理：2026-11-04。

**強勢股再加突破、拉回或跌破後收復條件，沒有一個設定在每日與間隔取樣都提高半年翻倍比例。**

比較沿用已看過的歷史，只追蹤價格；尚未加入帳戶、交易成本或完整技術理論。

研究問題：在相對強勢之外加突破、拉回或 2B 元件，能否提高辨識且保留足夠機會？

## 比較的是哪些股票與時點

資料為 2019-01-02～2026-08-14。基準是近 60 日漲幅排名前兩成；逐一加上「收盤創前 60 日新高」、「收盤高於 60 日均價、但近五日下跌」或「跌破近 20 日低點後在五日內收復」條件。例：股價在 100 元時符合條件，從當天起追蹤約半年（126 個交易日）是否曾達 200 元。每個方法家族只比較資料與後續結果都可判定的共同股票日期。

## 每日看較好的突破組，改成間隔取樣反而較低

| 條件               |               每日翻倍率 | 每隔 126 個交易日取樣 翻倍率 |
| ------------------ | -----------------------: | ---------------------------: |
| 近 60 日漲幅前兩成 | 9.43%（45,702／484,616） |                        8.79% |
| 前兩成＋60 日新高  |  11.82%（4,865／41,158） |                        7.23% |
| 前兩成＋五日拉回   | 9.24%（14,246／154,139） |                        9.86% |
| 前兩成＋跌破後收復 |      8.43%（840／9,969） |                       13.04% |

間隔取樣每 126 個交易日取一次觀察，減少同股連續日的重複。突破與跌破後收復兩組，在每日和間隔取樣的方向相反；它們也只涵蓋原強勢組中少部分最終翻倍的觀察。
