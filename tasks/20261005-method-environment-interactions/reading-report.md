# 型態加相對強勢：沒有跨面板一致改善

閱讀版更新：2026-11-02。這是保存證據的閱讀整理；可讀不等於策略通過或擁有者驗收。

## 問題與答案

在相對強勢之外加突破、拉回或 2B 元件，能否提高辨識且保留足夠機會？

**六個固定方法或交集均未晉級；沒有候選在每日與稀疏面板都提高相對強勢基準的翻倍比例。**

## 實際比較

每個 F10 突破、F32 拉回、F33 狀態式 2B 家族使用共同已知母體，比較原方法、F37、交集與無條件。主結果是未來 126 槽曾達觀察收盤兩倍，完整路徑才已知。624 比較、1,872 路徑摘要全部保留。

## 結果與分母

| 條件     |               每日翻倍率 | grid126 翻倍率 |
| -------- | -----------------------: | -------------: |
| F37      | 9.43%（45,702／484,616） |          8.79% |
| F10＋F37 |  11.82%（4,865／41,158） |          7.23% |
| F32＋F37 | 9.24%（14,246／154,139） |          9.86% |
| F33＋F37 |      8.43%（840／9,969） |         13.04% |

每日與稀疏方向相反，不能挑最好面板。F10／F33 交集也僅保留小部分 F37 贏家；保留率是實際交集，不是兩組總數相除。
