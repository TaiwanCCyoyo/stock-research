## 主要結果：加條件不是自動變好

以下「翻倍比例」的分母都是符合條件且結果已知的**股票日期觀察**。
日頻大量重疊，稀疏仍有跨股相依；均不是獨立交易成功率。

| 條件              | 日頻：翻倍／已知數  | 日頻翻倍比例 | 未翻倍比例 | 稀疏翻倍比例 |
| ----------------- | ------------------- | ------------ | ---------- | ------------ |
| 同母體全部觀察    | 129,964 / 2,380,225 | 5.46%        | 94.54%     | 4.97%        |
| 只看 F37 相對強勢 | 45,702 / 484,616    | 9.43%        | 90.57%     | 8.79%        |
| F10 突破          | 5,882 / 62,597      | 9.40%        | 90.60%     | 5.50%        |
| F10 ＋ F37        | 4,865 / 41,158      | 11.82%       | 88.18%     | 7.23%        |
| F32 拉回          | 27,145 / 412,995    | 6.57%        | 93.43%     | 7.94%        |
| F32 ＋ F37        | 14,246 / 154,139    | 9.24%        | 90.76%     | 9.86%        |
| F33 收復          | 4,351 / 91,982      | 4.73%        | 95.27%     | 6.58%        |
| F33 ＋ F37        | 840 / 9,969         | 8.43%        | 91.57%     | 13.04%       |

F10＋F37 的日頻比例升高，但稀疏反而低於 F37；F32／F33 組合則是稀疏較高、
日頻沒有改善。所有候選都缺少兩種取樣一致提高辨識比例的證據，不是單純卡在
研究者暫定的 25% 保留線。2019-2025 七個可評年度，組合優於 F37 的年數分別
為 5、2、1；單獨方法為 3、0、0。市場狀態及 63 日標籤都保留作診斷，未作救援。

## 沒翻倍者，有沒有少受傷

非翻倍觀察包含小漲與下跌，沒有只挑虧損。下面是日頻未翻倍組在完整 126 日
價格路徑的摘要；沒有交易成本、出場或資金分配，**不等於非命中帳戶損失**。

| 條件     | 期末價格變化平均 | 期末中位數 | 路徑最低價格變化 p10 |
| -------- | ---------------- | ---------- | -------------------- |
| F37      | +1.06%           | -2.91%     | -38.63%              |
| F10＋F37 | +0.08%           | -3.90%     | -39.72%              |
| F32＋F37 | +0.65%           | -3.58%     | -38.90%              |
| F33＋F37 | +2.24%           | -1.62%     | -37.91%              |

因此不能把「只挑強勢股」或「等拉回」直接理解為試錯損失很小；即使平均價格
略有上漲，尾端下探仍很深。這些路徑尚不能回答有止損／退出操作的 200 萬帳戶
會虧多少。全部路徑分布、成功等待時間、正負例、年度及背景資料都在產物中。
