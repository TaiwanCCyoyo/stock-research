# HHHL v4：無上方線是線索，越線加分未一致

閱讀版更新：2026-11-02。這是保存證據的閱讀整理；可讀不等於策略通過或擁有者驗收。

## 問題與答案

v4 原突破、上方壓力分組及同漲幅下的早期越線，與半年翻倍有何關係？

**全部真突破為 8.49%，主控制 8.86%；無線組較高，但同漲幅下早期越線沒有一致增益。**

## 實際比較

1,941 檔、51,731 個合格真事件；原日起算 126 共用觀察，首次達標前缺價即未知，先達標可保留 hit。共 1,080 固定比較；L20 仍用原 t0 目標及期限，不能重新起算半年。

## 結果與分母

| 組別     |    翻倍／已知 |  比例 |   未知 |
| -------- | ------------: | ----: | -----: |
| 全真事件 | 3,932／46,298 | 8.49% |  5,433 |
| 上方無線 | 2,943／30,402 | 9.68% |  3,889 |
| 上方有線 |   989／15,896 | 6.22% |  1,544 |
| 主控制   | 8,615／97,264 | 8.86% | 12,505 |

L20 pooled 已越線 11.25%、未越線 4.55%，但 0～10% 漲幅層為 4.66%／5.09%，不能把 pooled 差異全歸功於壓力線。

## 後續結果與修正

原雜訊每股首筆四格已更正：參考因子／126 為 91／1,631＝5.58%，不是舊 101／1,640。另 1,532 未到地標列的座標須讀為未知；主要結論不變。後續 variants 使用完整日曆主分母，7.81% 不與此 8.49% 互換。
