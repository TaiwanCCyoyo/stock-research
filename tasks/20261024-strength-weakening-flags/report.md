# 強勢後的轉弱訊號與倍數達標比例

28 個主要比較都呈現較低的翻倍比例；控制觀察點漲跌幅後，只有「收盤低於60日均線、觀察一年」在兩組強勢條件下仍有下降證據。這是已看過歷史的描述，尚不批准停損規則。

研究在 2010-01-04..2026-10-12 的 1,942 檔股票上完成，主要比較共 28 格，其中 2 格通過分層後仍下降的固定判讀，其餘 26 格只有合併下降的證據。完整設計、所有次要格與不明結果都保留，沒有挑選另一套條件或門檻。

這兩個較明確的比較是：起點已同時強於長均線與過去低價的股票，頭 20 個交易日內收盤曾低於 60 日均線，且到觀察點仍未翻倍。以起點起算的一年內，觸發組的翻倍比例較低；依當時漲跌幅分層後，下降方向仍通過兩種重抽樣區間。

代價也很大：在雙重強勢組最後確實翻倍的完整事件中，66.04% 在首次翻倍前曾觸發低於60日均線；雙重強勢＋大漲日組為 56.64%。這個代價觀察到首次達標前，並不限於頭20日，也不是停損模擬的錯殺率。

## 比較的母體與時間

- **雙重強勢（CORE）**：收盤較 MA240 高至少 60%，且是前 250 個交易日最低收盤的至少 2.5 倍。
- **雙重強勢＋大漲日（LEAD_B1）**：再加當日原始價格漲幅至少 9.5%。它是大漲代理，不能直接視為交易所實際漲停。此組只涵蓋 2015-06 以後，早期 7% 漲跌幅時代無法成立。
- **對照**：一般股票日，以及收盤達前 250 日新高且當日量至少為前 20 日均量 1.5 倍的股票日。兩組強勢與對照均使用相同 S6、每日口徑與有效標籤政策。
- **觀察點**：起點後第 5／10／20／40 個交易日；目標是起點收盤的 2／3／5／10 倍，期限從起點起算 126／252／504 個交易日，不在觀察點重新設基準。
- **風險集合**：起點到觀察點價格完整，且到觀察點仍未達到該倍數；觀察點當天已達標也排除。跌破任何價位本身不會排除事件。主格在第 20 日比較，後續分別剩 106／232 個交易日。
- **訊號分組**：在起點後到觀察點首次觸發者，與整段都已知而未觸發者比較；其餘保留為未知。未知不當作未觸發或零。
- **分母**：表內的達標率使用有效結果已知的每日事件；同一股票的連續日可能是多個事件。樣本支持度另外依「組別先冷卻20日，再拆訊號」的口徑判定，不能把每日事件數當獨立股票數。

這些條件都是固定的事前定義，沒有重新搜尋強勢組合。全部 4,110 個交易日都屬已看過資料；股票固定分半亦不是未看過的驗證期。

## 錯殺代價與未知上下界

代價從**全部 calendar-full 且有效達標的事件**算：T 為首次達標前已觸發，F 為已知未觸發，U 為旗標不明。
點估是 `T/(T+F)`，未知下界為 `T/(T+F+U)`、上界為 `(T+U)/(T+F+U)`；零分母保留不明。這些上下界不是信賴區間。
訊號到首次達標當天才出現不算達標前觸發；此口徑不套觀察點風險集合，故同組別／目標／期限／訊號在不同觀察點的代價相同。

| 低於60日均線、一年翻倍 | 達標前已觸發 T | 已知未觸發 F | 不明 U | 比例／未知下界／上界     |
| ---------------------- | -------------: | -----------: | -----: | ------------------------ |
| 雙重強勢               |          8,733 |        4,490 |      0 | 66.04% / 66.04% / 66.04% |
| 雙重強勢＋大漲日       |            695 |          532 |      0 | 56.64% / 56.64% / 56.64% |

不要把這個數讀成「第20日依該訊號出場會錯殺多少」：它觀察到首次達標前，時間更長，也沒有模擬何時能成交、出場價格、資金或持倉。表中未達標、結果不明與日曆截尾事件另有 counts；不把結果不明改列失敗。

## 訊號的精確意思

均線與布林訊號只要求觀察期間收盤在其下方，不要求剛從上方穿越。10%／15% 跌幅以固定起點收盤為基準。固定支撐低點是起點當時已確認、低於起點收盤的 1.5ATR 低點中**價格最高**的一個，不是最近一個；較低高點要等新高點確認才可用。
型態支撐與型態下緣缺少 S／L，在本研究一律不適用，沒有另造替代價位。完整格數 1,728 包含這兩個不適用訊號；其他缺值與不明亦完整保留。
