# 同群股票一起大漲後，二十日超額沒有穩定增加

把相近日期的重複觀察減少後，產業鏈一起大漲的事件，訓練期後續報酬落後全部合格股票的平均，驗證期則接近平均；尚未看到穩定比平均多賺的二十日結果。

分組使用 2026-08-23 成員名單回套歷史；原報告沒有列出完整訓練與驗證起訖，也沒有獨立任務文件。

## 先定義同群大漲，再看後面二十日

研究原問：同一產業鏈多檔股票一起大漲，是否伴隨成員或尚未大漲者接下來較好的報酬？

這裡的「點火」是同一天、一組合格成員至少三成上漲 5% 以上。例如某組有十檔合格股票，至少三檔當天從 100 元漲到 105 元或更多，就符合定義；這是門檻示例。落後成員指同組當天未達這個漲幅的股票。

時間順序是：事件日判定哪些組點火 → 追蹤成員往後二十個交易日報酬 → 減去同日起算的全部合格股票平均。研究比較產業鏈細分組與官方產業大分類，主要結果以間隔二十個交易日的取樣，減少相鄰日期共享行情。

## 產業鏈組的訓練與驗證方向不一致

| 產業鏈事件 | 事件數 |          全體成員超額 |    只看當天未點火成員 |
| ---------- | -----: | --------------------: | --------------------: |
| 訓練期     |    133 | −1.95 ± 0.61 個百分點 | −2.07 ± 0.69 個百分點 |
| 驗證期     |    128 | +0.12 ± 0.79 個百分點 | −0.50 ± 0.99 個百分點 |

超額是成員報酬減全部合格股票平均，也就是比平均多賺多少；± 後是原表估計誤差的尺度，並非成員漲跌的上下限。驗證期平均差距小於誤差尺度。官方大分類只有 20／8 個事件，對應估計更不精確。

同資料若每天取樣，驗證期全體成員讀數是 +1.65 ± 0.19 個百分點；相鄰兩日的二十日結果共享十九日行情。較疏取樣後降至 +0.12 ± 0.79，兩種結果對取樣方式很敏感。
