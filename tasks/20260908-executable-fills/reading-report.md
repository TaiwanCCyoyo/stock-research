# 改在次日開盤成交後，不設最低持有期的報酬大幅縮水

閱讀版更新：2026-11-04。數字沿用下列保存來源。

**研究問題：** 五檔綜合評分策略若不能在看到收盤訊號的同一價格成交，改成下一開盤、可用交易單位並計入滑價，原先的報酬還剩多少？

2024-01-01 至 2026-08-14，五檔策略改為次日開盤、只買整張、買賣各加 0.25% 不利價差後，不設最低持有期的報酬由本篇同收盤基準 154.5% 降至 −38.5%；至少持有 20 日則由 85.5% 降至 51.2%。兩者都使用已看過的期間，尚無獨立期間確認。

**主要限制：** 所有期間均已看過，零股開盤價是假設，模型未完整涵蓋排隊、部分成交與逐筆價格；保存報告另有一格執行錯誤尚無完成證據。

[五檔基準](../20260906-five-slot-baseline/report.md)採同日收盤成交，[穩健性確認](../20260906-five-slot-confirmation/report.md)已發現延遲敏感；本篇改用次日開盤與交易單位限制，並使用本次自己的同期間基準。

## 實際比較

一張是 1,000 股。A 組把買單向下取整為整張；預算不足一張就不買。B 組允許剩餘零股，但使用一般市場的原始開盤價，沒有量到零股自己的撮合價。

滑價是相對基準成交價額外加上的不利價差：25 bps＝0.25%。假設開盤 100 元，買進按 100.25 元、賣出按 99.75 元計算，手續費與交易稅另計。這是情境假設，不是實測市場滑價。

| 順序           | 模型處理                                               |
| -------------- | ------------------------------------------------------ |
| T 日收盤後     | 依已完成的收盤資料產生訊號                             |
| 下一交易日開盤 | 用開盤價加不利價差嘗試成交，並檢查整張／零股與成交限制 |
| 當日結束       | 未成交委託到期；後續依新訊號決策，不把缺行情補成成交   |

訊號在 T 日收盤後形成，嘗試於下一交易日開盤成交；無行情或不可成交的委託到期，不補造成交。A 組只買整張；B 組自 2020-10-26 起允許以原始開盤價買零股，屬較樂觀假設。測試 0／10／25／50 bps 滑價及最短持有零／20 日。

訓練期為 2019-01-02 至 2023-12-31；為比較零股制度另設 2020-10-26 至 2023-12-31 子期間；驗證期為 2024-01-01 至 2026-08-14。子期間不能與整段訓練直接比較。

| 驗證期情境     | 持有期零報酬 | 持有 20 日報酬 |
| -------------- | -----------: | -------------: |
| 本次同收盤基準 |       154.5% |          85.5% |
| A 整張、零滑價 |        28.0% |          64.6% |
| A 整張、25 bps |       −38.5% |          51.2% |
| B 零股、零滑價 |        49.2% |          26.7% |
| B 零股、25 bps |       −19.6% |          10.9% |

主要事前比較格為訓練子期間 A 組、25 bps、持有期零：3.3% 對同收盤 180.4%，僅保留約 2%。這個保留率是「策略淨報酬相除」，不是還剩多少本金；報告的 30% 門檻也不是 研究委託人 對策略的最終批准規則。

## 持有 20 日仍有正報酬，同期 0050 的保存結果更高

驗證期 A 組、25 bps、持有 20 日，200 萬元約成為 302 萬元，最大回撤 −28.2%，156 次買進、74 次未成交。原報告的同期 0050 比較為 +215.5%、回撤 −28.5%；在這個已看過期間，策略報酬較低，最大回撤接近。此處引用保存的基準，沒有重新建構總報酬或執行模型。

持有 20 日在訓練子期間 A 組、25 bps 的報酬 50.7%，相對同收盤 84.3% 約保留 60%。兩個持有期使用各自的同收盤基準；保留率差異支持成交敏感性隨持有設定改變。

## 未回答與資料缺口

保存報告缺少的是 2020-10-26 至 2023-12-31、允許零股、買賣各加 0.25% 不利價差、至少持有 20 日這一格的完成數字；來源記錄執行錯誤。它不是上表已列出的整張驗證期情境，本版只保留缺口，不描述目前執行狀態。交易撮合細節、獨立未見期間與符合 研究委託人 的最終接受標準也尚未完成。

## 與舊報告的數字怎麼接

本次基準訓練報酬由舊 228.0962% 變為 230.5334%，報告追到五筆新增股息，差約 2.4372 個百分點。這是輸入快照差異，不能用新分子除舊分母判定成交效果。本文比較均沿用本次同一組基準，不重算或改寫舊證據。
