# 箱型與收縮策略缺樣本，短線反彈的毛利又被成本吃掉

三種新方法各有不同瓶頸：箱型與價格收縮突破在單一產業的交易太少；短線反彈雖有較多交易，部分小幅毛利被成本抵銷。沒有單一方法與產業組合同時完成原定的兩期要求。

比較期間：訓練 2019-01-02 至 2023-12-31；驗證 2024-01-01 至 2026-08-14。

把五個產業合併後，箱型與收縮方法呈現正平均損益，但這是看過結果後增加的分析；原來逐產業的主要判定仍為未通過。

## 三種方法追蹤不同的價格過程

研究原問：改用價格收縮後突破、箱型突破或短線反彈，是否比原來三種進場方式更有優勢？[先前比較](../20260816-kline-strategy-category-fit/report.md) 提供三種價格進場的設計，本次新增：

| 方法                | 本次實作追蹤的過程                                           |
| ------------------- | ------------------------------------------------------------ |
| 價格收縮突破（VCP） | 回檔幅度逐漸縮小、成交量減少，之後放量越過轉折高點           |
| 箱型突破（Darvas）  | 價格離開已確認的整理區上緣，退出界線跟隨新箱底上移           |
| 短線反彈（RSI-2）   | 長期趨勢之上的股票短期急跌，等待回升；以兩日強弱指標衡量短跌 |

五個產業各 20 檔；訓練 2019-01-02 至 2023-12-31，驗證 2024-01-01 至 2026-08-14。每次進場固定 100 萬元；訊號比較讓每筆獨立計算，帳戶比較另用共用的 1,000 萬元資金。

## 合併後的正值，與原來逐產業的答案不同

原先三種方法 × 五個產業，共 15 組。要求兩期平均進場損益皆正且達到平倉樣本門檻的規則，以及勝過同籃持有的規則，分別都是 0/15 通過。

| 事後合併五產業：驗證期 | 平均每次進場損益／100 萬投入 | 已平倉數 |
| ---------------------- | ---------------------------: | -------: |
| 箱型突破               |                      +19.65% |      117 |
| 價格收縮突破           |                       +2.24% |       66 |

平均進場損益包含股息及期末尚未平倉部位；右欄只是已平倉數，並非左欄完整分母。部分箱型產業的利潤高度依賴期末未平倉市值。

短線反彈的金融組則有 821 筆已平倉：驗證期平均每筆毛利 +2,098 元，扣成本後為 −3,752 元。這一組更清楚地把「有小幅毛利」與「扣成本後仍有利」分開。

## 後續拆解：箱型優勢來自哪一部分？

本次六種方法比較已將舊三種方法以相同資料版本重跑，沒有沿用回補前的舊值。文獻方法在長均線、暖身資料與相對強弱排名上仍有改寫。

[停損隔離研究](../20260821-stop-mechanism-isolation/report.md) 固定進場、只換出場，發現箱底退出改善平均進場損益，帳戶風險規則卻未過。[MAE 補量](mae_retro.md) 量到每筆部位的較深逆行；[棘輪泛化](../20260822-ratchet-generalization/report.md) 進一步指出，這個跌幅與更長持有時間相伴。方法優勢與風險的來源，仍須按各自的比較拆開。
