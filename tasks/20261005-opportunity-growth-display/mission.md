# 時間調整的波段展示規則

Owner 在 2026-10-05 要求以波段為基礎，將長期累積漲幅轉成年化報酬；未滿一年使用實際漲幅，避免單日漲幅被年化放大。Owner 同意初始入選門檻 100%。這份記錄固定於新規則案例評估前；不是新的價格、波段偵測或策略驗收版本。

## 固定規則 `wave-growth-display.v1`

- 輸入是同一保存波段起點至觀察日、具有可靠價格連續性的報酬。保存 API 的 gain 使用百分點，公式內先除以 100；價格口徑沿用既有調整收盤，不宣稱含息或實際持倉報酬。
- 以日曆日差 / 365.25 表示年數。滿一年條件與年化分母使用同一約定，整日資料在第 366 日跨入年化，不混用 365 日門檻。
- 年數 < 1：展示指標 = 本波實際漲幅；不計算／呈現短期年化值。
- 年數 >= 1：展示指標 = `100 * expm1(log1p(gain / 100) / years)`，即 CAGR。`log(1 + R) / years` 本身是對數報酬，不直接標成年化百分比。
- 入選指標 >= 100%；UI 可調門檻，使用者變動須明示。比較使用絕對 1e-9 百分點容差處理浮點誤差，不依畫面四捨五入判斷。既有候選開始日期遮罩保留；完整波段目錄不因展示遮罩刪除。
- 以此展示指標計算 `(max(metric, 0) / 100)^2` 面積；指標兩倍，等效直徑兩倍。已有的市值乘數約定不變，缺可靠歷史市值時仍停用。
- 原始總漲幅、日期、CAGR 與實際／年化 basis 分開保存。缺價／連續性中斷、起點可能截斷、無效日期不能補成零或假裝知道完整起點；展示指標未知，完整記錄仍可查。
- 不改代表波段選擇。父子與跨界重疊仍用既有資料；同股票面積只計一次。整理期間指標可能降低，這是既有波段至觀察日速度的變化，不是新擬合或出場訊號。
- 產業最大值是族群內某一檔股票的最高展示指標，附該股票與 basis；不能稱全產業投資報酬或平均年化績效。

## 實作與保存

共享數學在 `research_core/wave_growth.py`，`wave-growth.v1` 可由歷史 API 與 `scripts/score_wave_growth.py` 讀取。網站使用這份指標；CLI 與 AI 可用同一函式／欄位，不另維護公式副本。沒有新的共享價格資料；來源是既有 2010-01-04..2026-10-02 快照及保存代表波段。

原 mission、價格、native 方法、catalog 與其 hashes 保留；不下載、不做全量波段重算。程式、契約及 CLI 會隨 Git 保存；大型原始快照仍依原 catalog 取得限制。

## 驗證計畫

先用可手算案例確認：一天 +10% 不入選；短期 +100% 入選；兩年 +300% 接近年化 +100%；365／366 日邊界；2012-11-12 至 2021-04-29 +1290% 為年化約 +36.49%；未知、截斷與負報酬保持正確語意。確認 API、CLI 和網站採相同百分點／日期口徑。

再在網站檢查 2021-04-29 的版圖、產業最大標籤、排序、門檻變更與個股原始漲幅。案例讀取與數學正確不能證明保存波段起點或分類已定案。飆股分類 session 負責跨目錄／研究契約核對；網站 session 負責介面及這份正式記錄。
