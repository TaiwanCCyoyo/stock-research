# 重試只多賺 3.49 萬元，延遲成交仍是缺口

閱讀整理：2026-11-04。

**加碼未成交後重試一次，原時點執行的帳戶多賺 34,908 元；所有交易延遲一天時是否仍改善，還沒有結果。**

只比較 2019–2023 年原時點執行的結果；同一重試規則在延遲、缺席及另一段未看過期間的表現尚未完成。

研究問題：加碼提案未成交後，只允許一次有界重試，能否改善原帳戶？

## 比較的是哪些股票與時點

2019–2023 年，以 200 萬元、最多同時五檔股票的帳戶比較：原本加碼單終止且完全沒買到就結束；新版本只再給一次買入機會。106 次原加碼提案中，7 次完全沒成交，5 次符合重試條件，最後 3 次買到。

表內「非命中」沿用原報告分類，指已結束、但沒有被列為捕捉到大漲的持股嘗試，包括小賺與虧損；其淨現金是這一組收支的合計。委託次數包含沒有成交的單，操作晚數是一晚有工作就計一次。

## 這份結果和後續研究的關係

[延遲成交研究](../20261002-one-lot-delay-resumption/execution-v4.md)的帳戶只保留原每日淨利的 52.898222%，未過 70% 要求；本次正常重試沒有推翻它。[加碼階段診斷](../20261002-add-stage-diagnostic/report.md)則提供加碼有沒有成交的分組背景。

## 這次回答到哪裡

小幅收益伴隨額外委託與操作。這次回答了原時點執行的差異，尚未回答原先最棘手的延遲成交問題。
