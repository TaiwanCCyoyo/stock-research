# 至少持有 40–80 日：訓練表現較好，驗證期留下的漲幅份額不足

閱讀版更新：2026-11-04。數字沿用下列保存來源。

**研究問題：** 最低持有20日是在保護整理中的持股，還是在延後處理輸家？延長或縮短它有何代價？

三十檔模型延長最低持有期到 40／60／80 日後，三種設定雖在訓練期通過，到了 2024-01-01 至 2026-08-14，都未保留基準八成的大漲股票漲幅份額。縮短為零日也未改善訓練期報酬與回撤。

這裡的漲幅份額，是固定期間內事後大漲股票中，策略取得的漲幅總和除以這批股票可得漲幅總和；沒買到的也留在分母，並非帳戶報酬。

**主要限制：** 僅有單一驗證視窗，較短設定沒有開啟驗證；舊週轉與成本上限是當時規則，不是現在仍有效的研究委託人硬門檻。

[加碼訊號研究](../20260905-add-trigger/report.md)發現許多持股到第 20 日已掉出排名，引出本篇對最低持有期的檢查。[同期間出場比較](../20260906-exchange-rate/report.md)後來更正了本篇跨期間比較的推論。

## 實際比較與答案

最低持有期是買進後禁止「因排名變差而賣出」的等待天數；例如設定 40 日，先持有滿 40 個交易日，再依排名決定是否退出，不代表第 40 日一定賣。

「大波段份額」（原表 pool share／pool_capture）把母體股票實際取得的漲幅加總，再除以同一母體可得漲幅的總和；沒買到的股票也留在分母。例如份額 0.20 代表取得這批股票可得漲幅總和的兩成，不是帳戶賺了 20%。

「帳戶年周轉」把每次買進金額占當日帳戶淨值的比例加總，再除以年數；3 倍表示一年累計買入約三個帳戶規模，不是只交易三次。最大回撤則是帳戶從先前高點到後續低點最深的一次跌幅。

資料期間：訓練期的完整日曆起訖未列於本任務 mission 與 report；驗證期為 2024-01-01 至 2026-08-14，見本文所引 exchange-rate 的同期間比較。

固定V8、30檔、動能排名出場，只改最低持有天數。訓練最初六格，看到邊界結果後依追加契約測30／80／100日；不是一開始就固定的九格。訓練飆股母體64檔，驗證72檔，pool share只能同窗比較。

| 設定     | 訓練報酬／最大回落 | 驗證大波段份額 | 驗證帳戶年週轉 |
| -------- | ------------------ | -------------: | -------------: |
| 0日      | 112.7%／−41.4%     |         未評估 |         未評估 |
| 20日基準 | 148.7%／−31.0%     |         0.1895 |           8.57 |
| 40日     | 185.8%／−31.3%     |         0.1366 |           5.08 |
| 60日     | 154.0%／−32.1%     |         0.1372 |           3.50 |
| 80日     | 181.9%／−28.9%     |         0.1247 |           2.72 |

驗證期三個新設定的大波段份額均低於該窗基準的 80% 門檻 0.1516。80日雖守住當時週轉與成本要求，捕捉率僅0.722，仍未通過。185.8%可以作為歷史訓練結果展示，但不能單獨引用為獨立有效證據。

## 尚未回答與後續修正

沒有驗證0–30日的全部短持有設定；也沒有證明20日是最優解。集中度放行條件的「顯著高於」原先沒有數字，後來採目的解讀放行，這個研究自由度不能抹去。

原報告把訓練期give20與驗證期hold80並排推論「同一條取捨曲線」。exchange-rate後續明確撤回跨視窗比較，改用同窗配對，結果有有限機制差異。execution-reality記錄研究委託人不再把2%成本磨損設為硬上限；歷史失敗判定保留，現在討論則應聚焦成本後報酬和手動可執行性。
