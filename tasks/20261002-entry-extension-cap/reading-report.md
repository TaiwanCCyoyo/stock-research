# 進場漲幅上限：少做很多交易，也犧牲大部分收益

閱讀版更新：2026-11-02。這是保存證據的閱讀整理；可讀不等於策略通過或擁有者驗收。

## 問題與答案

首次進場限制近 60 日漲幅不超過 50%，能否降低試錯成本而保留收益？

**這個固定上限雖降低交易與侵蝕，卻只保留每日對照約 13.69% 淨利，未通過原篩選。**

## 實際比較

2019–2023，初始 200 萬、最多五檔。對照為期末兩個安靜建議日的每日帳戶；只變動首次進場的 ret60≤50%，沒有低排名遞補。

## 結果與分母

| 指標                   |     每日對照 |      上限組 |
| ---------------------- | -----------: | ----------: |
| 淨利（元）             | 2,934,085.15 |  401,796.20 |
| 完成非命中淨現金（元） |  +396,434.48 | +148,852.13 |
| 委託／操作晚數         |     714／549 |    267／218 |
| 命中發行人數           |            6 |           1 |

淨利保留低於事前 70%，命中發行人也少於至少兩檔的要求。已知二十次非命中窗口較小，但仍有未結束嘗試，不能宣稱全域最大損失已知。

## 後續結果與修正

上游每日對照本身已在延遲測試失敗；它是研究比較基準，不是已接受策略。後續加碼階段診斷保留本上限失敗判斷。

## 能支持的決定與未回答部分

支持停止這個精確設定的晉級；未回答換其他上限或排名是否有效，也不授權調參救回。成交、公司事件、每日估值與未完成損失預算仍限制投資解讀。

**主要限制：僅適用此排名、部位與 ret60 上限的已暴露期間；不能推論所有避免追高的方法無效。**
