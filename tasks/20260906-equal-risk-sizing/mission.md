# 任務卡：等風險下單——既然贏家認不出來，就別再認，改成讓每次嘗試賠一樣多

`20260906-equal-risk-sizing`，2026-09-06。**訓練期先跑，驗證期封存到全部關卡通過為止。**
本文件在跑任何一格之前寫完。

## 1. 為什麼這是唯一剩下的方向

`20260906-loss-anatomy` 量到一件事，它把「什麼時候買賣」這整個軸關掉了：

**三天內就賠錢賣掉的交易，和抱過十天賺錢的交易，在買進的當下分不出來。**
買進前三天的排名中位數 44 對 46（訓練期）、48 對 34（驗證期）；
「前一天就在前 5 名」的比例是 24% 對 34%（訓練期）、**28% 對 17%（驗證期，方向相反）**。

**這條線試過的每一條進場規則都建立在「分得出來」這個前提上，而那個前提被量掉了。**

所以這張卡**不再試圖分辨**。它不挑「該做哪一次嘗試」，
它讓**每一次嘗試承擔一樣的風險**：波動大的股票買少一點、波動小的買多一點，
使得同樣幅度的停損對帳戶造成同樣的傷害。

**這也是擁有者原話的直接實作**：「停損時都是小賠」——現在的做法每筆金額固定 40 萬，
所以一檔 ATR 6% 的股票跌一根，比一檔 ATR 2% 的股票痛三倍。**等風險下單把那個差異拿掉。**

## 2. 手臂與公式

`candidates/rotation_ranker_v13.py` = V8，只改部位大小：

```
部位金額 = min(risk_pct / atr_pct, max_position_pct) × 期初資金
```

`atr_pct` 是 ATR(14) ÷ 收盤價，取自 `20260826-runner-retention/retention_features.parquet`，
**只讀進場當天的值**。以**期初資金**計價而不是當下淨值，與 `equal_notional_quantity` 一致——
**這樣本卡與基準之間唯一不同的東西是部位形狀，不是部署路徑。**

**上限是設計常數，不是掃描的參數。** 實測買進當天的 `atr_pct` 從 1.1% 到 11.3%，
所以未設上限時 `risk_pct = 0.007` 會讓單一低波動的名字拿到帳戶的 **108.8%**。
**固定 `max_position_pct = 0.30`**（現行固定 20% 的 1.5 倍），寫死不掃。
**這是一個我選的自由度，寫在這裡而不是藏在程式裡。**

**沒有 ATR 讀數的名字不買**——沒有資料不等於低風險。

### 校準（跑之前先量的）

買進當天 `atr_pct` 的中位數是 **0.0397**、平均 0.0411。所以：

| `risk_pct` |  平均部位 | 中位部位 | 超過 40% 的比例 |
| ---------: | --------: | -------: | --------------: |
|      0.005 |     14.2% |    12.6% |            1.5% |
|      0.006 |     17.0% |    15.1% |            2.7% |
|  **0.007** | **19.8%** |    17.6% |            4.1% |
|      0.008 |     22.6% |    20.1% |            5.9% |
|      0.009 |      ~25% |     ~22% |               — |

**`risk_pct = 0.007` 的平均部位是 19.8%，剛好對齊基準的固定 20%**，
所以家族取 **0.005 / 0.006 / 0.007 / 0.008 / 0.009**，讓基準落在正中間。

### 錨點（已跑，通過）

`risk_pct = 0` 讓手臂退回繼承的等金額下單。實測 **228.0962% / 1091 筆買進**，
與 `20260906-five-slot-confirmation` 的 V8 基準**完全一致到小數第四位**。
**沒有這個錨，底下每一格的比較都建立在一個沒驗證過的基準上。**

## 3. 對照組：問一個更尖銳的問題

`sizing_column = "control"` 用**同一個經驗分布**抽出一個假的 ATR，抽籤只看股票代號的雜湊值。
**部位大小的離散程度與真 ATR 完全一樣，但不帶任何關於這檔股票的資訊。**

`20260905-add-trigger` 量過一個 `crc32(代號)` 的雜訊對照組做出比每個真候選量都大的效應。
所以這裡的對照組問的是：**幫助來自「把風險拉平」，還是只要「部位大小有變化」就夠了？**

## 4. 預先宣告的關卡

全部在訓練期判定，全部相對於 `all` / k5 / er30 / hold0 的等金額基準：
**228.1% / −37.5% / 最壞連續 20 次虧損 38.2%。**

| #   | 關卡                                           | 門檻                                             |
| --- | ---------------------------------------------- | ------------------------------------------------ |
| A   | **機制真的有作用**：每筆損益佔期初資金的標準差 | 比基準**低 ≥ 15%**                               |
| B   | 最壞的連續 20 次虧損                           | **比 38.2% 低**                                  |
| C   | 報酬保留                                       | **≥ 70% × 228.1% = 159.7%**                      |
| D   | 最大回落                                       | **比 −37.5% 淺**                                 |
| E   | **平台**                                       | 五個 `risk_pct` 裡有 **3 個連續**同時過 A~D      |
| F   | **對照組必須失敗**                             | 對齊離散度的假 ATR 版本**不得**形成 3 格連續平台 |

**關卡 A 是照 `20260906-five-slot-confirmation` 的教訓寫的**（「不要寫一個候選者自己過不了的門檻」）：
它檢定的是**這個手臂宣稱在做的事**——把每筆損益的分散度壓下來——
而那是等風險下單機械上必然會發生的，所以它是一個手臂**應該**過得了的門檻。
**如果連 A 都沒過，代表程式沒有照設計運作，那要先修程式而不是下結論。**

**關卡 B 用「比基準低」而不是 codex 的 20%**，理由是這張卡的機制主張是「拉平每次嘗試的風險」，
不是「消滅連賠」。**20% 那條線仍然會報告，但不當作通過與否的依據。**

## 6. 先天限制

**`max_position_pct = 0.30` 是我選的，而且沒有掃描。** 換一個上限結果會變。
選 0.30 的理由（基準的 1.5 倍）寫在第 2 節，**它不是從結果挑的，但它也不是被檢定過的。**

**`atr_pct` 只有一種波動度定義。** 用標準差、真實波幅的其他窗長、或按產業標準化，
都可能給出不同答案。本卡不宣稱 ATR(14) 是最好的風險代理。

**訓練期單一視窗。** 而且候選者的驗證期已經被讀過（`20260906-five-slot-baseline`），
所以若通過，開的是**這五格新設定**的驗證期。
