# 任務卡：「沒有夠好的就不買」——用絕對標準做出空手，而不是看大盤

`20260906-absolute-entry-bar`，2026-09-06。**訓練期先跑，驗證期封存到全部關卡通過為止。**
本文件在跑任何一格之前寫完。

## 1. 為什麼不是照字面做「看大盤空手」

擁有者要的是「行情不好就盡量空手」。**由上而下的那個讀法已經被 `20260823-regime-overlay`
測完了**：10 個偵測器 × 2 種反應，加上進出場濾網，**29 條臂 0 條通過**。

要點，避免重跑：

- **偵測器本身是好的。** `d1_ma200`（0050 跌破自身 200 日均線）在 13 年、9 次回落上，
  平靜日誤報只有 **0.6%**，蓋住 2015 的 70%、2018 的 60%、2022 的 87%。
- **但配上空手會變差。** `cash__d1_ma200` 驗證期 **44.8%**，當時的基準是 **81.8%**。
- **看起來會贏的那一族（站上季線的比例）在門檻之間完全不穩。** 驗證期 br35 → 9.0%、
  br45 → 70.6%、br55 → 120.9%；**而訓練期那三格全在 166~192%，看不出來。**
- **硬天花板：可回測範圍只有一次完整空頭年（2022），而且在訓練期。**
  一次事件驗不了一條「空頭時空手」的規則，**這一點到今天沒變。**

## 2. 由下而上的那個讀法沒被測過，而且現行規則在結構上說不出那句話

**這個書架的每一個計分欄位都是橫斷面百分位排名。** 一檔名字今天排前五，
不管市場上是滿地收縮的底部還是什麼都沒有，它的排名都一樣高。
所以 `order[:top_k]` 永遠是五個名字，**書架永遠滿倉**。

**排名說不出「今天大家都很爛」，只有絕對水準說得出。**

所以本卡的濾網讀的是**原始特徵值**而不是它的排名，並且和一個固定門檻比。

**用哪一個特徵不是我挑的，是 `20260906-five-slot-confirmation` 的 Gate B 指出來的**：
拿掉 `r_contraction` 讓五格書架從 228.1% / −37.5% 掉到 **104.5% / −58.7%**，
而拿掉其餘七項中任何一項都還在 145~244% 之間。**收縮是那個分數的核心**，
而收縮的底部正是行情不好時會變稀少的東西——**所以一個絕對的收縮門檻應該自己就會產生空手，
不需要任何人去看指數。**

## 3. 手臂與格子

`candidates/rotation_ranker_v12.py` = V8 + `filter_column` / `max_value`。
**候選名單上原始值高於門檻的名字不買，而且那個格子就空著**——
**書架不會往排名下面找人來補**，因為總是有東西排第六名，補了就等於沒有濾網。
出場端完全不動。

基準與被濾的對象都是 `all` / `top_k=5` / `exit_rank=30` / `min_hold=0`，NT$2,000,000，
即 `20260906-five-slot-baseline` 的那個候選者。**它訓練期 228.1% / −37.5%，
最壞的連續 20 次虧損吃掉期初資金的 38.2%。**

**門檻（訓練期前五名的實際分布，先量過再選）**：原始 `contraction` 中位數 0.902、
p25 0.782、p75 1.062。取 **0.80 / 0.90 / 1.00 / 1.10 / 1.20**，
分別讓 71% / 50% / 33% / 21% / 13% 的候選名額空著。
更低的門檻不取：0.70 會讓 62% 的交易日完全買不到東西。

**控制組**：同一支手臂改讀 `vol_ratio`。**門檻用「填滿比例」對齊而不是用數值對齊**
（兩個欄位的數值不可比）：**1.483 / 2.043 / 2.739 / 3.528 / 4.411**，
填滿比例與上面五格完全相同（28.9% / 49.6% / 67.4% / 79.5% / 87.2%）。
Gate B 說 `vol_ratio` 是這個分數最不依賴的一項（拿掉它反而 243.7%），
**所以如果效果來自「收縮」而不是「少買一點」，控制組應該做不出同樣的東西。**

**關卡 A 是這張卡存在的理由**：`20260906-five-slot-confirmation` 就是敗在它，
而「爛行情裡照樣把五個位置塞滿」正是連續虧損會連續的機制。

**關卡 D 防的是一個具體的假通過**：門檻設得太鬆的話濾網幾乎不擋人，
那一格會複製基準的數字並「通過」B 和 C，但它什麼都沒做。

**關卡 F 是這條線的教訓**：`20260905-add-trigger` 量到一個 `crc32(股票代號)` 的雜訊對照組
能做出比每一個真候選量都大的效應。**這裡的對照組不是雜訊而是「另一個也會讓你少買的欄位」，
它問的問題更尖銳：效果是來自收縮，還是只要少買就好？**

## 6. 先天限制

**訓練期單一視窗，而且候選者的驗證期已經被讀過。** 若通過，開的是**濾網那三格**的驗證期，
不是候選者本身的（那個已經開過）。

**門檻是從訓練期前五名的分布挑的。** 五個值涵蓋 p25~p90，**沒有針對結果調整過**，
但它們確實是看著訓練期的分布選的，**這是一個必須承認的自由度**——
關卡 E（平台）與 F（控制組）就是用來限制它的。

**`contraction` 是 ATR(14)/收盤 相對自身 60 日均**，所以門檻的意義是
「這檔股票現在的波動相對它自己最近的常態」，**不是相對別的股票**。
這正是要它做絕對判斷的原因，也表示**它對市場整體的波動水準是有反應的**——
在系統性高波動時期整批股票都會被擋下來，那是預期中的行為而不是缺陷。
