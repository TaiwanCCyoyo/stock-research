# 「沒有夠好的就不買」：負面。而順手查到的一件事，把整條「空手」的路封死了

任務 `20260906-absolute-entry-bar`，2026-09-06。**六道門檻寫在跑之前；平台關卡 0 格通過。**

## 0. 三句話

**第一，絕對門檻擋不住連續虧損。** 五個門檻的最壞連續 20 次虧損是
**30.3% / 35.2% / 36.2% / 39.1% / 38.2%**，門檻是 20%，未加濾網是 38.2%。
**沒有一格接近門檻**，而報酬從 232.8% 一路掉到 61.9%。

**第二，門檻越緊，買得越少、賺得越少，但賠得沒有比較少。**
這說明**濾網把賺錢的機會和賠錢的機會用差不多的速度一起濾掉了——它在減量，不在選擇。**

**第三，也是這張卡真正的產出：那段連賠不是空頭，是一個月內的絞殺。**
最壞的 20 次虧損擠在 **29 天（訓練期 2021-07-14~08-12）** 與 **34 天（驗證期 2026-06-25~07-29）**
之內。而 **0050 對自身 200 日均線這個偵測器，在這兩段裡標成空頭的比例都是 0%。**
**大盤好好的，這個書架自己在流血。**

## 1. 為什麼做這張卡（`mission.md` 第 1、2 節重述）

擁有者要「行情不好就盡量空手」。**由上而下的讀法 `20260823-regime-overlay` 已經測完**——
29 條臂 0 條通過，最好的偵測器配空手在驗證期是 44.8% 對基準的 81.8%。

**由下而上的讀法沒被測過，而且現行規則在結構上說不出那句話**：所有計分欄位都是橫斷面百分位排名，
排名前五永遠有五個名字，**書架永遠滿倉**。排名說不出「今天大家都很爛」。

所以本卡讀**原始** `contraction` 值配固定門檻。選這個特徵不是我挑的，是
`20260906-five-slot-confirmation` Gate B 指出來的：拿掉 `r_contraction` 讓書架從
228.1% / −37.5% 掉到 104.5% / −58.7%，其餘七項拿掉任一個都還在 145~244%。

## 3. 這張卡最有價值的部分：那段連賠長什麼樣子

|        | 最壞的連續 20 次虧損 | 期間                    |    跨幾天 |
| ------ | -------------------: | ----------------------- | --------: |
| 訓練期 |          −763,887 元 | 2021-07-14 ~ 2021-08-12 | **29 天** |
| 驗證期 |          −661,866 元 | 2026-06-25 ~ 2026-07-29 | **34 天** |

**這個書架一年做約 220 次完整來回，所以「連續 20 次虧損」≈「一個月內幾乎全軍覆沒」，
不是「一年的低潮」。** codex 合約 gate 2 的 20 次在慢速書架上是很長一段，
**在這個快速書架上是一個月**——同一條門檻在不同換手速度下量的是不同的東西，
這一點對兩條線都重要。

**而且每年的賠錢比例非常穩定**（訓練期 60/57/62/71/62%，驗證期 56/61/61%），
**所以連賠不是「某一年變差」，是隨時可能出現的一個月。**

## 4. 所以那段連賠到底是什麼

資料指向一個具體的東西，但**本卡沒有檢定它**，只是記錄：
`min_hold_bars=0` 的五格書架靠**快速換手**運作（訓練期 1091 次買進、驗證期 721 次碰過 401 檔）。
**在盤整或震盪的一個月裡，排名會不斷翻動**，書架就一直買進、幾天後掉出前 30、小賠賣出、再買。
**那是排名的抖動，不是市場的下跌，也不是選股的失誤**——所以偵測器看不到、絕對門檻也擋不住。

如果這個說法是對的，**能動的東西在「換手速度」而不是「什麼時候買」**。
但 `20260906-five-slot-baseline` 已經量到 `min_hold=20` 把驗證期從 154.1% 打到 47.2%，
**所以單純放慢是不行的。這是一個真實的張力，本卡不假裝它有答案。**

## 5. 這張卡不能推論的事

**訓練期單一視窗，驗證期完全沒開**（依 `mission.md` 第 5 節，訓練期沒過就不開）。

**Gate F 的通過是空的**（第 2 節），不得引用為「效果專屬於收縮」。

**門檻是看著訓練期前五名的分布選的**（p25~p90 五個值），這是一個自由度。
Gate E 與 F 就是用來限制它的，而兩者都沒有救起任何東西。

**第 4 節是假說不是結論。** 「排名抖動造成連賠」沒有被檢定過。

## 6. 下一步

**「行情不好就空手」這條路，兩個版本都關閉了。** 建議把這件事告訴擁有者時，
連同第 3.1 節的 0% 一起講——**因為那是「為什麼不做」的證據，不只是「做了沒用」。**

**還沒被碰過的是第 4 節那個假說：連賠是換手速度的產物。**
可檢定的版本例如：**同一個名字在被賣出後的 N 天內不得再買回**（防止反覆進出同一檔），
或**同一天最多只換一格**。兩者都不放慢整體換手，只擋住抖動——
**與 `min_hold` 是不同的機制**，而 `min_hold` 已經被證明會毀掉這個書架。
