# 2010 起歷史波段資料：展示辨識結果，規則仍未定

閱讀版更新：2026-11-02。這是保存證據的閱讀整理；可讀不等於策略通過或擁有者驗收。

## 問題與答案

如何把既有更長行情整理成可查的波段、階段及候選，而不是誤以為資料只從 2019 開始？

**已完成 2010 起的連續歷史辨識；它是初步描述資料，沒有證明事前選股或交易能力。**

## 實際比較

2,075 個代碼分層保存：1,942 個 metadata 股票、28 創新板做分析；104 身分未明及 0050 不納入股票機會數。固定 segments／filter 各三尺度，對完整序列分析、不按年重置。

## 結果與分母

保存 53,188 個共享波段、790,250 筆候選與 7,875 個代表區間。這些是方法／尺度產物，不是獨立成功交易。代表顯示用 segments/balanced；波段暫定至少 60% 累積漲幅，尚未驗證為策略門檻。

官方報價為主、Shioaji 補既存缺口且保留來源。2019 是舊研究選窗，不是資料起始年。

## 後續結果與修正

catalog-v2 修正浮點連續性判定，保留原 v1；原報告表示實際受影響漲幅為零，不能因此忽略兩版語義。後續多次驗證補強不是多次研究成功。舊文的 legacy worktree 路徑僅為歷史來源，現行取得方式依資料交接文件。

## 能支持的決定與未回答部分

可做回溯瀏覽與下一研究案例索引；200 家分類證據隊列、歷史母體與備份恢復仍不能由交付報告推定完成。Git metadata 不是完整價格／擬合資料，本版也未存取原行情。

**主要限制：目前身分與分類參考不等於完整歷史母體；早期公司事件與分類有效日有缺口，展示漲幅不是含息或可成交報酬。**
