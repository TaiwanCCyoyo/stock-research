# 等三晚再買，未命中持股合計虧損縮小，但已有一串交易更差

閱讀整理：2026-11-04。

**連續三晚符合才進場，淨利保留 97.23%、委託減少；但一串二十次非命中持股的最大中途累積損失，比原版本更大。**

三晚確認組仍有未結束持股，因此該組所有二十次序列中最差的一串尚無法確定；原版本的全域值已知，候選已有一串較差，足以判定未過原定條件。

研究問題：要求連續三晚符合進場條件，能否減少非命中侵蝕與操作？

## 比較的是哪些股票與時點

2019–2023 年，相同 200 萬元、最多五檔。原版本第一次符合就可提出進場；新版本必須連續三晚都符合。例如星期一首次符合，星期二不符合，連續次數就中斷。這裡比較的是最早的未篩選試算帳戶，與後來一張試單研究的基準不同。

表內「非命中」沿用原報告分類，指已結束、但沒有被列為捕捉到大漲的持股嘗試，包括小賺與虧損；其淨現金是這一組收支的合計。委託次數包含沒有成交的單，操作晚數是一晚有工作就計一次。

## 淨利保留 97.23%，但連續二十次的損失更大

| 指標                                 | 原未篩選版本 |     三晚確認 |
| ------------------------------------ | -----------: | -----------: |
| 淨利（元）                           | 3,225,828.61 | 3,136,623.38 |
| 完成非命中淨現金（元）               |  -768,520.40 |  -321,088.61 |
| 委託                                 |          813 |          681 |
| 已知連續二十次最大中途累積損失（元） |   528,270.11 |   546,898.11 |

把已結束的非命中持股按原順序，每連續二十次合成一組，檢查從零開始累積收支，在這二十次進行途中曾經損失最多多少。原版本有 159 組、新版本有 129 組可完整計算；三晚確認組已有一組中途損失達 546,898.11 元，到第二十次結束時則為 531,322.11 元。原版本的全域值已知；三晚確認組仍因未結束持股而無法確定全域最差一組。這些數字不是整個帳戶從最高點回落的幅度。

## 這份結果和後續研究的關係

採用完整 v3；v1／v2 原文明定為未完成執行，不是先前策略失敗。v3 保留公司認股拒絕及估值假設，不把零扣款說成權利沒有價值。

## 這次回答到哪裡

已結束非命中持股的合計虧損縮小，但連續序列的最大中途損失惡化。原條件要求兩者都不惡化，因此這個三晚確認設定沒有通過；延遲執行與另一段歷史的結果仍未完成。
