# 五檔確認：較好的單點結果沒有通過穩健性檢查

閱讀版更新：2026-11-02。以下整理保存的研究與後續更正，未重跑市場計算。

## 原本的問題

五檔全特徵基準是否能承受參數變動、移除單一特徵、不同年份、漏日與延遲成交，並控制連續未命中的壓力？

## 目前能回答的事

五檔基準沒有通過整體確認：參數未形成穩定區間，延遲一天只保留約 61% 訓練期報酬；修正後連續損失則是訓練期不過、驗證期通過當時界線。

## 實際比較與答案

候選固定全特徵、五檔、退出排名 30、最短持有期零、200 萬元；原比較尺為三十檔動能、最短持有 20 日，訓練期報酬 146.9%、回撤 −31.1%。當時候選條件要求至少相同報酬，且回撤不差於 −36.1%。

| 檢查               | 保存的結果                                                    | 可以回答什麼                           |
| ------------------ | ------------------------------------------------------------- | -------------------------------------- |
| 參數鄰域           | 退出排名 30 時僅七檔點通過，沒有連續三點；五檔自身回撤 −37.5% | 不能選五檔單點為穩健平台               |
| 移除特徵           | 八次移除有六次未通過；移除收斂後報酬 104.5%、回撤 −58.7%      | 有特徵依賴；但原設定本身已未過回撤條件 |
| 年份分段           | 訓練五年有四年正報酬，驗證三段均正報酬                        | 不是僅靠單一正報酬年份，但不是獨立驗證 |
| 隨機漏 10% 日期    | 五種子訓練報酬 178.1%～211.6%，最差約保留 78%                 | 通過這個漏日模型的條件                 |
| 延遲一日           | 139.1% ÷ 228.1% 約 61%                                        | 未通過報酬保留條件                     |
| 修正後二十次未命中 | 訓練 23.8%、驗證 8.9%                                         | 對照當時 20% 界線，一過一不過          |

移除特徵未通過不全等於該特徵不可替代；其中一些只是繼續未過候選原本已不合格的回撤要求。漏日是整日略過操作的模型，不能讀成隨機少做 10% 訊號或真實請假恢復操作。

## 未回答與決策意義

不應批准此候選，也不應由這次失敗推論所有五檔策略都失敗。這份證據指出原設定對成交時機敏感，下一步理解結果應先看成交假設，而非繼續挑好看的參數。

## 後續修正

原連續虧損算法的 38.2%／33.1% 已由 9 月 7 日更正取代。新算法串接含小賺但未命中的嘗試，以進場日帳戶淨值正規化並複合，並非每日帳戶最大回撤。後續 executable-fills 正式分開下一開盤、整張／零股與滑價情境；閱讀時不能只停在本篇延遲一日測試。

## 閱讀界線

全部期間都已被探索或檢視，沒有新增未見資料；隨機漏日、延遲成交與連續嘗試診斷分別回答不同問題，不能互相代替。

原始研究判定仍保留；這份閱讀版可供理解與討論，不代表策略獲准或新增獨立驗證。
