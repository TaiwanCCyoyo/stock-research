# 波段參與診斷：延後退出沒有補回選股與試單問題

閱讀版更新：2026-11-02。這是保存證據的閱讀整理；可讀不等於策略通過或擁有者驗收。

## 問題與答案

每日與每週退出帳戶，是否參與歷史翻倍波段，又在哪裡耗損？

**每週退出在波段高點仍持有的案例僅多 2 段，不能抵銷它已失敗的非命中損益篩選。**

## 實際比較

比較同為初始 200 萬、最多五檔的保存每日與每週帳戶，沒有另跑策略。主集合是 960 檔的 1,434 段完整、無旗標波段；被排除的 1,127 段含跨界、未完成與品質問題，不能直接視為失敗。

## 結果與分母

| 觀察                   |        每日 |        每週 |
| ---------------------- | ----------: | ----------: |
| 波段期間曾持有         |         142 |         132 |
| 高點收盤仍有可交易股數 |          75 |          77 |
| 首次持有晚於翻倍資格日 |          96 |          88 |

分母是事後波段，不是交易命中率；同一嘗試可能跨多段，現金表已按嘗試去重。

## 能支持的決定與未回答部分

可用來討論進場太晚與無波段重疊嘗試的成本，但許多未持有案例沒有進場追蹤，原因仍未知。不可按事後波段排除股票，也不支持救回每週退出設定。

**主要限制：事後波段及目前族群分類不能當成當時可知訊號；持有高點不等於賣在高點或賺完整波段。**
