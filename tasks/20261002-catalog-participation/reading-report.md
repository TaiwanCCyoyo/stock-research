# 改成每週退出，波段高點只多留住兩段

閱讀整理：2026-11-04。

**每週退出在波段高點仍持有 77 段，每日退出是 75 段；只多兩段，原本非命中持股轉虧的問題仍在。**

波段是看完後來價格才辨識，分類也用目前名單；高點當天仍持有，沒有表示帳戶在高點賣出。

研究問題：每日與每週退出帳戶，是否參與歷史翻倍波段，又在哪裡耗損？

## 比較的是哪些股票與時點

2019-01-02～2023-12-29，把相同 200 萬元、最多五檔的每日與每週排名退出帳戶，對照事後整理的歷史翻倍波段。採用 960 檔股票的 1,434 段完整且沒有品質標記的波段；另外 1,127 段有跨界、未完成或品質問題。例：某段從 100 漲到 200 元，表格問帳戶有沒有在這段期間持有，不要求從 100 元一路抱到 200 元。

表內「非命中」沿用原報告分類，指已結束、但沒有被列為捕捉到大漲的持股嘗試，包括小賺與虧損；其淨現金是這一組收支的合計。委託次數包含沒有成交的單，操作晚數是一晚有工作就計一次。

## 1,434 段歷史波段中，高點仍持有 75 段與 77 段

| 觀察                   |        每日 |        每週 |
| ---------------------- | ----------: | ----------: |
| 波段期間曾持有         |         142 |         132 |
| 高點收盤仍有可交易股數 |          75 |          77 |
| 首次持有晚於翻倍資格日 |          96 |          88 |
| 完成非命中淨現金（元） | +396,434.48 | -415,417.46 |

分母是事後波段，不是交易命中率；同一嘗試可能跨多段，現金表已按嘗試去重。
