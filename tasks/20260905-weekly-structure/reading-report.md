# 週線結構：收斂訊號值得追蹤，但尚未證明可預測報酬

閱讀版更新：2026-11-02。以下整理保存的研究與後續更正，未重跑市場計算。

## 原本的問題

週線結構是否提供既有排名以外的資訊，並能區分後續上漲與下跌的機會？

來源界線：本任務沒有保存 mission.md；這個問題依原報告整理，無法據此認證事前登記。

## 目前能回答的事

週線收斂在訓練期的股票日樣本中出現較好的長期兩端命中差，但樣本高度重疊，尚不能稱為經驗證的預測能力。

## 實際比較

研究比較週線多頭排列、收斂、站上均線與兩底四種特徵。實際均線為 5／10／20 週，並非原先較長的 20／60／120 週設定。與排名的相關性使用 top 60 股票日樣本：66,557 筆、1,110 個交易日；這些不是 66,557 個獨立投資案例。

預測部分每隔 20 日取樣，以「達到上漲門檻的比例 − 達到下跌門檻的比例」比較分組；250 日視窗使用 +100%／−50%，60 日視窗使用 +30%／−23.1%。

| 收斂最低十分位            | 原報告記錄              |
| ------------------------- | ----------------------- |
| 250 日兩端命中差          | 0.096                   |
| 相對同日基準的平均差      | 約 +0.040               |
| 勝過同日基準的日期比例    | 65%                     |
| 平均每日入組股票數        | 41 檔                   |
| 60 日相對同日基準的平均差 | 約 +0.017，勝日比例 51% |

兩端命中差不是勝率，也不是報酬率。配對差依同日比較計算，不能直接拿不同彙總欄位相減代替。五年內 250 日視窗約只有四段不重疊期間，因此長期結果的獨立資訊量遠少於表面筆數。

## 未回答與決策意義

這份報告支持保留週線收斂作為候選特徵，沒有回答可否直接交易、是否優於現有策略、加碼後是否改善帳戶。部分交集組別少於 30 檔，不能穩定比較。相關係數低於設定上限也只代表資訊不完全相同，不代表具備新增獲利能力。
