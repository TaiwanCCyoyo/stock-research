# 拉長排序視窗減少換手，卻沒有達到報酬改善要求

最長視窗的一個設定把驗證期年換手降到每部位 2.59 次，報酬為 +82.4%，接近基準的 +81.8%；但最大回撤更深，八個候選都未達原定的報酬改善要求。

本篇報酬比較的驗證期：2024-01-01 至 2026-08-14；共同訓練起日的差異保留如下。

共同訓練起日仍有兩種記載：任務寫 2020-01-01，結果表寫 2020-02-03。本篇保留結果表與這個未對齊處，維持「歷史與待整理」。

## 改變看多長的漲幅，持股與退出規則相同

研究原問：排名不只看近期漲幅，改看更長期間或同時考慮波動，能否改善十檔策略的報酬？

基準用最近 20 與 60 個交易日漲幅排名；候選拉長到 120、250 日，或按漲幅相對價格波動評分。持有前十名、退出名次及最短持有期固定。約一年的長視窗版本，另有跳過最近二十個交易日的設定（skip_250_20），用較早一段漲幅而非最近一個月排序。

完整訓練執行期為 2019-01-02 至 2023-12-31；但長特徵需要較多過去行情，共同評分期間因此另設起點。任務與表格的共同起日差異仍未解決。以下驗證期均為 2024-01-01 至 2026-08-14。

## 換手少了，最大跌幅卻更深

| 驗證期帳戶比較     | 原 20／60 日排名 | 長視窗、跳過最近二十日 |
| ------------------ | ---------------: | ---------------------: |
| 淨報酬             |           +81.8% |                 +82.4% |
| 每部位每年完整換手 |          8.89 次 |                2.59 次 |
| 最大回撤           |           −53.3% |                 −60.2% |

最大回撤看帳戶由高點到後續低點的最深跌幅。兩個報酬數字相近，是這段歷史的觀察；來源沒有提供確認兩者等效的檢定。

原要求是候選驗證期報酬至少為基準的 1.5 倍。以基準報酬 100% 作定義示例，候選需達 150%，不是期末資產變為基準的 1.5 倍。八個候選無一達標，也未形成相鄰參數皆合格的區間。

候選持股的成交金額較高，顯示交易較活躍；成交金額與公司市值是不同量，沒有在此建立同義關係。
